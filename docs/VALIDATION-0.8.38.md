# 鲸梦 0.8.38 —— 眼睛可见性专项修复

## 根因
用户提供的原版鲸鱼 SVG 在 viewBox 1391×1024 中使用约 28×30 SVG 单位的透明镂空表示眼睛；当启动屏图标缩至 20–46 CSS px 高度后眼睛成为亚像素或约 1 px，浏览器抗锯齿下难以辨认。

## 修复
- 保留原始鲸鱼 path 完整几何，用透明 SVG mask 将同一只眼睛所在位置 (772,479) 镂空放大至半径 38 SVG 单位。
- 不新增实心眼睛，不添加外框，不修改鲸鱼主体和嘴部；透明镂空适配主题渐变。
- 插件 icon.svg、assets/whale-brand-icon.svg 与启动屏内嵌 SVG 采用同一修复。
- 窄窗口 Icon 最小尺寸 36×26 CSS px。
- 启动节奏、标题及功能保持 0.8.37 不变。

## 验证
参考同目录 QA、真实 Chromium 截图、SVG 样图，以及压缩包内完整性检查。Windows DSH Electron 实机仍需用户确认。
