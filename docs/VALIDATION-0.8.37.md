# Whale Dream 0.8.37 · 启动屏慢节奏品牌演出热修复

## 修复基线与变更范围

基线为用户上轮确认的 `dsh-whale-dream-0.8.36.tgz` 编译分发包。该包不含完整 TypeScript 原始工程，因此本次直接修改发行版中的 `lib/startup/boot.js`、Host 注入模块 `lib/startup/host.mjs`，并将完全相同的启动代码嵌入 `lib/client.js` 回退入口。

用户明确取消鲸鱼跃水动画。新版仍采用**无 Canvas/视频/React 动效依赖的启动 DOM/CSS**，但替换了准确的鲸鱼图标与节奏。

- 图标：使用用户提供的 `viewBox="0 0 1391 1024"`、**单条路径**的鲸鱼 SVG；启动屏 `currentColor`，无外框、底板、附加圆形/眼睛/轮廓。插件清单 `icon.svg` 也改为同款无外框 SVG，保留原蓝色 `#4D6BFE` 便于非 CSS 环境识别。
- 标题：`鲸梦 探索未至之境`，不包含 `×` 或其他连接符。
- 主要节奏：0.35s icon → 1.09s「鲸梦」→ 1.75s「探索」→ 2.47s「未至」→ 3.30s「之境」→ 4.10s 一次性微光签名 → 5.17s 开始退出；约 5.55s 完成过渡。
- 可读性：最后两个字符完成滑入后约 1.2s 的完整阅读时间；光感强调只执行一次，不循环、不覆盖文字；不会再在 3s 内强制结束。
- 性能：不引入新的 npm/React/motion/字体依赖，不使用 requestAnimationFrame，约 5.5s 后释放 Overlay、CSS、定时器、MutationObserver 与监听器；同时保留约 7s 的防卡死清理保护。
- 主题：修复 Host 将内置「干净明亮」`mist`、`Material 粉` `rose` 误判为深色的兼容问题；启动阶段直接复用编译包中八套内置主题 `glow` 渐变数据。自定义合法渐变的优先级高于预置背景。
- 保留：启动设置开关、Esc 与点击空白跳过、减少动画效果、Host 首屏注入和客户端 fallback；未重写其他业务组件。

## 自动化测试结果

1. `npm run check`：prepack 语法检查通过；**19/19** 项发行包 Node 专项测试通过。
2. Chromium 真实 Host 注入预览：八套内置主题各自测试了原版 SVG 路径（4861 字符）、单个 path、无 rect、完整文字显示、一次性微光触发，以及 icon 与文字同色，**8/8 通过**。
3. 截图取样：八套主题的中心邻近背景与标题色，对比度分别为：abyss 16.41、aurora 16.23、nebula 16.47、ember 16.49、midnight 17.45、ivory 15.77、mist 15.36、rose 15.69（取样点与实际渲染像素对应，非多点最小对比度保证）。
4. 窗口：1920×1080、560×700、320×568，文本未越过窗口边界，Esc 能提前清理 Overlay；**3/3 通过**。
5. 减少动画效果：直接显示完整品牌标题并短暂停留后自动关闭，Chromium 单独实测通过。
6. 对比上版：共 66 个原有文件逐字节不变；`lib/client.js` 除版本号和内嵌启动代码外的所有字符一致。

## 安装方法

备份 `~/.dsh/whale-dream.json` 及信息栏账本，卸载同名旧版 `dsh-whale-dream`，在 DSH 插件管理中选择本地 `dsh-whale-dream-0.8.37.tgz` 进行安装并启用，再从托盘彻底退出并重启 DSH。保留旧版 0.8.36 TGZ 可用于回滚。安装包本身不覆盖用户配置文件。
