## 已验证的变化

- 费用项保留范围短标和准确金额，删除费用图标；本地估算仍保留 `≈`。余额、计价时段、会话费用这三项常显只保留钱包一个图标，有字段时不再重复显示总统计图标。
- DS 常显严格显示「高峰 · 2h30m后空闲」或「空闲 · 1h59m后高峰」等紧凑格式，去掉 DS 前缀和日月图标；完整中文倒计时、北京时间与模型来源仍在 title、无障碍说明和详情中。
- 订阅额度、token、参考单价、模型名称、时间和日期去除重复图标，必要的额度窗口、方向箭头、币种、参考标记与单价单位保留。额度、缓存与上下文比例条纵向放在数值下方。
- 可见内容与隐藏测量继续共用 SummaryField，分别测量纯内容基线与图标回退基线；首字段前不再计入已删除总图标的间距。
- 修复短末项边界：先判断全部字段是否放得下，只有确实溢出才预留 +N，避免本可完整显示却错误收纳。
- 在显式模拟宽度 1400 → 620 → 320 → 1400 下验证完整显示、收纳、仅图标回退与恢复。极窄模式不叠加 +N，仍可通过按钮打开详情；Escape 关闭并恢复焦点，保存的选择和顺序不改变。
- 用户自选列表、自动模式、模型切换、真实零与未知值、币种隔离、图表键盘操作、订阅多窗口及云账单单位的既有断言继续通过。

独立只读审查也确认了组件与测量基线一致。本轮没有在真实浏览器测量节省的像素，因此不提供未经实测的缩短百分比或像素值。
