# 鲸梦实况窗

从官方 DSH 桌面版的插件页安装 `dsh-whale-dream-1.0.0.tgz`。实况窗需要包内包含当前系统的原生组件。Mac 对应 Apple 芯片和 macOS 13 或以上版本，Windows 对应 x64。在 **设置 → 鲸梦主题 → 实况窗** 启用功能，可选择胶囊、刘海、极简刘海和收起时的显示方式。

## 顶部位置

实况窗停靠在屏幕顶部，Mac 上会避开系统菜单栏和屏幕刘海。按住收起的实况窗，或按住展开面板顶部居中的拖动条，即可沿顶部左右移动。把鼠标拖到另一台显示器后，实况窗会移到该显示器的顶部。松手后会保存显示器和横向位置，重新启动实况窗时会恢复。断开该显示器时会暂时回到主屏，重新连接后回到原位置。

## 会话标签

- 悬停展开后，可单击标签、在标签区滚动滚轮或用左右箭头切换会话。点击会话标题或旁边的斜箭头图标，或双击标签，可在 DSH 打开该会话。右上角的新会话按钮会打开 DSH 的新会话。
- 有新回复的会话优先，同组以回复时间倒序排列。其他会话继续沿用置顶与最近活动顺序。已归档会话会从标签中移除。
- 加载环表示思考中，亮色点和提示边表示有新回复，灰色点表示空闲。多个会话同时处理时，各自独立更新。

## 用量与回复

展开时，标题栏右侧依次显示余额和费用，金额保留一位小数，悬停可看原值。小时、天和周等多周期额度会分别记录，标题栏显示一项额度和其余项数，悬停可查看全部周期。积分、Token 和其他用量沿用渠道提供的单位。DSH 新增或变更模型时，实况窗跟随对应会话选择的服务商和模型。未提供账户额度的 API 会显示「—」，已记录的用量仍可显示。

回复时间和用时紧跟「最近回复」标题，右上角显示 DSH 模型选择器中的名称。回复内容的标题、段落、列表、表格和代码块统一字号，借助字重、缩进和间距区分层次。可以滚动或悬停展开阅读预览内容。点击会话标题可到 DSH 查看特别长的回复或富媒体。会话状态可在各标签上查看。

全部空闲时，实况窗显示「探索未至之境」和账户可用余额。有新回复时，实况窗根据收起显示设置呈现会话和费用信息。

切换标签后，可在底部输入文本，再按 Enter 或点击「发送」。使用中文输入法时先确认候选词。若会话正在思考、已归档或暂时无权发送，实况窗会提示并保留输入。

将本地文件拖到实况窗回复区，也可在输入时粘贴文件或剪贴板图片。Mac 上从 Finder 复制并按 ⌘V 粘贴，Windows 上从文件资源管理器复制并按 Ctrl+V 粘贴。上传沿用 DSH 的附件规则。草稿文字和附件与 DSH 主窗口按会话同步。点附件旁的 × 可将它从草稿移除。点击附件可进入 DSH 对应会话，在 DSH 查看支持预览的内容。

## 完成提醒与待确认事项

在设置里可分别开关完成闪烁和提示音。有未读回复时，实况窗会持续提醒，查看后停止。精简动效会改用静态高亮。主界面正在查看会话时，回复完成仍可响一声。设置页可试听。

当前会话出现工具审批、方案确认或提问时，可在实况窗核对内容、选择选项并提交。审批和方案详情可滚动，操作按钮留在底部。多道问题逐题查看，切换问题保留当前答案。支持跳过的提问可跳过本题，方案使用 DSH 提供的选项。需要主界面才能完整展示的请求，可以点击会话标题到 DSH 处理。

## 验收流程

1. 将收起和展开的实况窗分别向左、向右拖动，再拖到另一台显示器。确认停在所选显示器顶部，重新启动实况窗后恢复到松手时的位置。
2. 在标签区用滚轮和左右按钮切换两个不同 API 渠道的会话。核对回复上方的账户用量、「最近回复」标题后的时间和用时以及右上角的模型名称。检查回复结构、统一字号和悬停阅读。点击标题或斜箭头图标，确认 DSH 打开的是对应会话。完成后应保留新回复提醒，查看后恢复空闲。
3. 置顶一个较早完成的会话，确认它排在未置顶的会话之前。归档后确认它退出标签列表。
4. 在空闲会话尝试文本回复，再关闭并重启实况窗，核对形状与收起信息设置是否记住。
5. 在实况窗内拖入文件或粘贴图片，切换到 DSH 检查同一会话的草稿。移除附件后确认两处同步，再点击实况窗内的另一项附件，检查 DSH 打开对应会话。
