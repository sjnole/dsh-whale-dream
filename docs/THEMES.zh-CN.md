# 0.8.7 主题、外观、圆环与信息栏使用说明

## 当前外观表现

新建和历史会话共用完整场景尺寸。输入框不会把整幅动画缩成小图，只在需要时平移主体，让脸部或故事核心尽量露出；大载体允许局部经过输入框后方。两种会话切换时保持同一进度和比例，位置柔和衔接。历史正文的淡化规则继续保留，无需新增设置。

0.8.2 的美术重做范围为「星空与光影」「微缩世界」「完整演出小游戏」，各 5 项；机械与小伙伴做适度细化，重点机器人。原海洋、经典游戏与植物的美术保留。

连续点击仍会显示点阵反馈；翻页、投递、伙伴回应和光影动作会先完成当前过程，再接受下一次场景动作，避免反复从头开始。梦境之书翻开的新世界会继续演出。输入框变高、主题变更或窗口调整不会清空同一外观的会话进度。

所有入口都在 **设置 → 鲸梦主题**。首页分为三个同级分类：

| 入口 | 内容 |
| --- | --- |
| 主题配色 | 推荐主题、我的方案与当前搭配；从「我的方案 → 创建新主题」编辑配色、背景、圆环。 |
| 外观与动态 | 七类外观选择；点击互动、按分钟间隔更换、动态强度、显示范围，以及海洋字符或非海洋纹理设置。 |
| 信息栏 | 输入框 SJ 圆环左侧的常显内容、勾选与 ↑↓ 排序；账本导出、清空与必要的账户查询凭据。 |

首页三个分类均不显示主题保存区。创建页底部保留「保存当前搭配」，点击「保存方案」后回到「我的方案」。默认主题只更换主题部分；自定义方案保存和恢复配色、背景、外观及圆环的完整视觉设置。信息栏单独保存，切换默认主题或自定义方案均不改变其常显内容和顺序。

新会话标题为 **鲸梦×探索未至之境**，只替换这段标题文字，保留原图标与「预览版」标识。

## 先分清默认主题与自己的方案

| 选择 | 会改变什么 | 会保留什么 |
| --- | --- | --- |
| 推荐的默认主题 | 原版主题配色、渐变/壁纸与材质默认值。 | 当前外观、是否显示、动态参数、自动更换方式与间隔、SJ 动效与刻度偏好，以及独立的信息栏设置。 |
| 我的方案 | 恢复保存时的完整搭配，包括外观类别与全部视觉偏好。 | 模型、推理等级、团队开关、会话内容与独立的信息栏设置。 |

默认主题有沉静蓝、极光青、星云紫、余烬橙、子夜黑、iOS 扁平、干净明亮、Material 粉八套。它们使用 Dream Skin 11.7.0 原参数，不再给每套主题指定一种动物。

例如你正在用「樱花树」，从星云紫切到 iOS 扁平，仍然是樱花树，自动配色时，颜色会按新主题协调。若你在「我的方案」使用之前保存的「像素夜航」，则按那份完整方案恢复游戏外观、配色、背景与圆环设置。

## 选择动物、游戏和植物

进入首页的 **外观与动态**：

1. 选择「动物 / 游戏 / 植物」分类。这里只浏览，不改当前画面。
2. 点击一张外观卡片。卡片对勾与“当前”提示会更新，外观立即应用。
3. 想一直使用时保持 **固定使用**；想自动变化时选择 **按间隔更换**，再填写 **更换间隔（分钟）**。

「显示动态外观」可以单独关闭。关闭时选择另一张卡片只记住选择，不会自动打开；再次开启后显示最后选中的外观。

8 种海洋保留原字符渲染器及其 ASCII、中文汉字、Kanji 设置。30 种非海洋场景采用专门设计的像素簇：不同部位使用不同大小的块面、轮廓与高光，不再用同样大小的字符覆盖整幅画。它们的「像素纹理」提供 ASCII、汉字和 Kanji，「纹理颗粒」与字体仅调整少量细节，主要轮廓保持完整。非海洋纹理颗粒范围为 0.75–1.35；旧值超出范围时按有效范围显示和绘制，原存档不被强行改写。

海洋、游戏、植物使用各自的构图与运动，并覆盖完整会话场景。植物保留固定根茎，花叶与茎秆分别摇动，落瓣、飘叶、种子或水波穿过更广范围。五款游戏按会话宽高铺开棋盘、星场、多层横版关卡和蛇行路线；命中、匹配、落地与吃食产生对应反馈。背景主体可以经过正文后方，已有消息不会强制把它们移到两侧或角落。

游戏仍是自动演示，无需用键盘控制角色。背景画布不接收指针事件；点击反馈被动观察合适的空白或可编辑输入框点击，正文、代码复制、链接、表格和输入框继续使用 DSH 原交互。

卡片显示实际渲染器生成的静态帧，与生产背景共用绘制代码；不是独立的近似图标。分类网格从目录动态生成，无固定数量槽位。

新增四类的 20 项完整演出细节见 [外观原方案](APPEARANCES-0.8.0.zh-CN.md)。每项下方都有简短的点击用途说明，不增加一大组专用设置。

### 点击互动

「点击互动」位于外观页上方，默认开启。关闭设置后，在新会话或历史会话的空白处，或在可编辑的聊天输入框中点击即可查看；设置里的外观卡片用于选择，不是试玩区域。升级会保留之前的互动开关。

| 当前外观 | 点击时的点阵反馈 |
| --- | --- |
| 海洋动物 | 水波与水点，继续触发原有鱼群惊散。 |
| 游戏 | 宝石、方块、火花、横版像素与食物颗粒。 |
| 植物 | 花瓣、花朵、竹叶、莲花与蒲公英种子。 |
| 星空与光影 | 星环、极光、光核、棱镜与星图；卫星绕行、光波传播、聚散和补绘同步回应。 |
| 微缩世界 | 书页、帆船、果实、怀表、信封；对应翻页、鼓帆、收果、亮灯、投信。 |
| 机械与小伙伴 | 机器人、声呐、磁铁、扳手、风铃；角色会观察、挥手、抛接或修补。 |
| 完整演出小游戏 | 能量、护盾、星星、钥匙、矿车；真实充能、范围受击、路径提示和特殊货物。 |

微缩世界的一次翻页、收果或送信会先完成；忙碌时连点仍显示轻量反馈，不把已在进行的故事重置。其他小游戏保留多个已接受点击的结果，不因下一次点击让敌人复活或让车上货物消失。

效果随当前外观主色和明暗主题适配，短暂出现后消失。它独立于尾迹强度和正文后方的背景淡化；把尾迹设为 0 不会关闭点击反馈。

输入框的效果显示在输入卡片内部的局部装饰层，透明且不接收指针事件；点击仍交给原编辑器处理，不改变焦点、选区或草稿。启用「输入时暂停」时，背景动画与空白背景互动会暂停，主动点击输入框仍有局部反馈。

正文、消息容器、代码、按钮、链接、菜单和 SJ 圆环不触发；只读、禁用或非编辑态输入区域、右键及背景拖选不触发背景效果，输入框文字选择仍交给原编辑器处理。页面隐藏和离屏期间暂停互动。外观已隐藏、系统开启减少动态效果，或者当前显示范围不包含历史会话时，页面会显示对应说明；恢复条件后自动继续，不需要重新安装。

### 按分钟间隔自动更换

在 **外观与动态** 中选择 **按间隔更换**，填写 **更换间隔（分钟）**。可填 1–10080 的整数，默认 60 分钟，按 Enter 或点击其他位置后生效；填写 30 表示从现在开始，每 30 分钟换一次同类外观。开关附近显示当前类别、间隔和下一次更换时间。想一直使用当前外观时，选择 **固定使用**。

| 操作或情况 | 行为 |
| --- | --- |
| 开启「按间隔更换」 | 保留当前外观，从此刻开始完整倒计时。 |
| 修改分钟数 | 从修改时刻重新计时，不沿用旧截止时间。 |
| 到达间隔 | 在当前类别内选另一种，排除当前外观。 |
| 关闭应用、休眠或暂停后错过期限 | 打开或恢复时只补换一次，再开始新的间隔，不快速连换。 |
| 点击具体外观卡片 | 退出自动更换，固定使用选中的外观。 |
| 点击分类标签 | 只浏览卡片，不改变当前外观和更换范围。 |
| 选择默认主题 | 保留当前外观、开关、间隔和计时，不重新配对外观。 |
| 使用已存自定义方案 | 恢复保存的外观与间隔；启用自动更换的方案从应用时刻重新计时。 |

动物在 8 种海洋动物内更换，游戏和植物各在 5 种内更换。每次排除当前外观，但不是固定顺序轮播，也不保证一轮中每种只出现一次。自动更换不改变主题配色、渐变、壁纸、动态强度和 SJ 设置；自然轮换也不会把已存方案误标为人工修改。

旧设置或方案已开启每日随机、但没有分钟字段时，升级会保留一天的频率，转换为 1440 分钟，并在首次载入后开始计时。可以随时改为其他时长。新配置默认 60 分钟且默认固定使用；没有应用关闭后的独立后台服务。

### 动态与阅读

「轻柔 / 舒适 / 灵动」一次调整适合阅读的速度、丰富程度、可见度及帧率。海洋类参数与新场景参数独立保留，切回海洋时仍使用之前的字符和鱼群设置。

**细调动态**按当前外观显示适用项：海洋有游动、体型、鱼群、摆尾和尾迹；游戏与植物有场景速度、大小和丰富程度。**阅读与性能**统一控制新会话/历史会话可见度、正文后方淡化、输入暂停和帧率。海洋继续提供**字符样式**和**字符细节与字体**，并保留网格、眼睛和彩色点缀参数；其他类别显示**像素纹理**、**纹理颗粒**与纹理字体。纹理变化不会把完整植物或游戏场景重新压成整幅字符格。

自 0.8.3 起，插件自动根据持续绘制开销临时降低帧率，有余量后逐步恢复，最高不超过已设上限；不会改写设置、缩小外观或重置场景进度。高 DPI 的背景内部像素预算也自动生效，不需要新增配置。较旧电脑可以从 20 FPS 开始，通常先用 30 FPS；实际结果可用随包离线自检页查看，方法见 [0.8.3 历史性能报告](PERFORMANCE-0.8.3.zh-CN.md)。其中数据属于历史版本，0.8.7 的实际检查记录以 [VALIDATION.md](VALIDATION.md) 为准。

「正文后方淡化」只降低装饰像素的强度，保留当前渐变和消息原有底色。所有类别与鲸鱼共用历史可见度和正文淡化规则；此项不会改变运动路径或搬移场景。希望正文后方更明显时，可降低淡化值或提高历史会话可见度。窄窗口会调整主体尺寸以保持主要轮廓可见。

## 调整渐变与图片

进入 **主题配色 → 我的方案 → 创建新主题 → 背景**，选择背景类型：

| 类型 | 用途 |
| --- | --- |
| 主题原版渐变 | 恢复当前主题自己的多层渐变，保留自定义界面配色。 |
| 自定义渐变 | 调整 2–8 个颜色的排列、方向与分布。 |
| 图片壁纸 | 选择本地图片或输入图片链接，可进一步调整构图。 |
| 不使用壁纸 | 使用页面底色，动态外观仍由自己的开关控制。 |

打开“背景”页本身不替换原来的背景。明确选择 **自定义渐变** 时开始使用可编辑渐变；接下来的改色即时生效。

渐变的日常操作只需点色块、输入 HEX、上下箭头或拖动排序。**均匀分布 / 反转顺序**可快速整理。打开 **精细调整** 后，每行显示位置百分比，并提供准确角度或放射中心；相同位置可形成清晰色界。

已有自定义完整配色时，文字明暗按「配色」页的明确色值显示；未自定义配色时，可使用渐变的自动、浅色文字或深色文字适配。背景与配色不会出现两个互相冲突的设置入口。

本地图片会沿用原插件压缩流程。图片链接输入后需点击 **使用图片**。**图片位置与缩放**可调整主角位置，**更多图片功能**保留最近图片、链接/文件夹轮播和同一 URL 的定时刷新。轮播先准备至少两张图片；文件夹由运行 DSH 的设备读取，离线 HTML 不能读取目录。

**透明、模糊与材质**统一调整页面、侧栏、输入区、弹层和性能模式。侧栏联动跟随的是页面背景透明度。菜单和弹层可保留较多底色以便阅读。

## 调整 15 项配色

进入 **主题配色 → 我的方案 → 创建新主题 → 配色**。每个色值旁都有具体用途，点色块或输入 HEX 即可：

| 分类 | 可编辑颜色 |
| --- | --- |
| 文字与强调 | 强调色、主要文字、次要文字、边框。 |
| 界面材质 | 页面底色、侧栏、输入区、弹层与菜单、用户气泡、代码与表格。 |
| 外观 | 外观主色。所有类别跟随此色，游戏和花叶的次级色会协调派生。 |
| 推理圆环 | 圆环底色、文字、轨道、强调。 |

「界面明暗适配」用于原生图标和代码高亮的深浅模式，下方已填写色值保持不变。透明度仍在背景的材质设置中。**恢复自动配色**撤回手动配色，让界面和外观颜色跟随当前主题与渐变，背景内容保留。

## 创建、保存和使用方案

1. 打开 **主题配色 → 我的方案**，点击 **创建新主题**。当前搭配作为起点，不必重新选择默认主题。
2. 在 **配色 / 背景 / 圆环** 中调整，效果立即生效；外观和动态仍在同级 **外观与动态** 页面配置。
3. 在创建页底部 **保存当前搭配** 中检查或修改方案名称，点击 **保存方案**。
4. 保存成功后回到 **我的方案**，新主题加入列表并处于使用中。创建始终生成新方案，不覆盖此前正在使用的自定义方案。
5. 点击其他方案的 **使用**恢复整套搭配。当前方案已被调整时，卡片提供 **恢复已存版本**，可恢复收藏中的效果。

创建页的 **返回我的方案** 返回列表；同一设置窗口内切换页面会保留名称草稿。未保存时不会新增收藏，当前设置仍会自动记住。「当前设置已保存」表示正在使用的效果已保存，不表示已经创建了命名方案。

更新已有方案时，在当前已修改方案卡片的 **管理 → 保存修改** 中操作。该操作只针对当前使用的方案；其他卡片不提供覆盖入口。需要另存时使用 **创建新主题**，为新的搭配命名保存。

卡片的 **管理**还提供重命名与删除；删除会再确认，并保留当前显示效果。保存失败后保留名称与当前修改，可重试保存；重试同一记录，避免生成重复方案。名称无效的提示只出现在保存区。

自定义方案最多 30 套、名称 1–40 字且不能重名、全部合计不超过 2 MB；内嵌图片计入总量。文件夹和网络图片保存其引用，不把整个图片目录复制到另一台设备。这些方案限制不限制外观目录数量。

完整方案包含主题/全部语义配色、渐变或壁纸及构图、材质、全部外观参数、自动更换开关与分钟间隔、SJ 的动效/刻度/星点。模型、provider、推理等级、团队开关、聊天内容和独立的信息栏勾选/排序不属于方案。

从 0.5.0 起移除了「扩展与维护」页面，本版继续保持。新建、更新和恢复完整搭配统一从「我的方案」进入，不需要再维护另一套主题包入口。

## SJ 推理圆环

输入区的小环来自 SJ 0.1.4 的实际生产组件。点击展开，使用当前会话真实模型目录、推理档位和团队状态；只显示宿主提供的能力。

选择模型后模型列表关闭、圆环保留。列表打开时，首次点击圆环内其他位置只关闭列表；外点或 Escape 关闭圆环。历史会话关闭团队协作保留原版确认。圆环内盘和菜单有独立底层，配色跟随当前主题和圆环语义色。

**主题配色 → 我的方案 → 创建新主题 → 圆环**只放动效、已经过的刻度和星点说明。模型、等级与团队操作继续在会话输入区完成。切换默认主题保留这些动效偏好；自定义完整方案可恢复保存的视觉组合。

## 信息栏

新会话和历史会话都在 **输入框内 SJ 圆环左侧**显示信息栏。默认「自动适配」，根据当前账户和模型实际返回的数据选择有用内容。DS 项仅在适用的官方模型显示一个当前状态及距下一时段的倒计时。利用左侧剩余宽度，实际放不下时才收进 `+N`，点击可展开详情。

在首页同级 **信息栏** 页切到「自选常显」，可勾选需要的项目，用 **↑ / ↓** 调整顺序，共 14 项可选。切回自动适配不会删除自选组合。常显每项使用图标或必要的短文字其中一种；费用保留范围短标记并删除图标，DS 状态省去 DS 前缀与日月图标，已有内容时不重复显示总统计图标。缓存和上下文细比例条置于数值下方。完整含义可通过悬停、键盘聚焦及详情查看。

「恢复默认」回到自动适配及初始自选搭配。旧初始默认组合升级为自动，改过的组合及空列表保留为自选，不强行添加 DS 项。全部取消后仍保留信息图标，关闭「显示会话信息」则隐藏入口。

详情提供费用趋势与明细、输入输出比例、DeepSeek 时段条与两档参考单价。信息栏与主题方案独立保存，配色随当前主题适配。数据口径、导出、清空及完整使用方法见 [INFO.zh-CN.md](INFO.zh-CN.md)。
