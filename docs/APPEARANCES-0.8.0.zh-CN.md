## 星空与光影

1. **月环行星**（`ringed-planet`）：倾斜星环的行星、轨道卫星；球体缓慢自转，星环有前后遮挡，远处偶有流星。点击后星环从点击方向逐段亮起，卫星加速绕行一圈，再恢复。
2. **极光帷幕**（`aurora-curtain`）：两三层半透明极光带，宽窄、远近不同，光沿帷幕流动。点击产生沿极光传递的柔和光波，向两侧舒展再回落。
3. **星云潮汐**（`nebula-tide`）：有明暗层次的星云聚拢、旋转、舒展；内部凝结亮星，亮星离开后星云合拢。点击产生引力涟漪，附近星尘聚成光核后散开。
4. **棱镜流光**（`prism-ribbons`）：透明棱镜、穿过的细光束、折射后的几条柔和色带；棱镜轻转，光带角度跟随。点击使棱镜朝点击方向倾斜，光束展开成扇形再收回。
5. **流星织梦**（`meteor-weave`）：流星沿不同弧线经过，尾迹编织成帆船、山峰、鲸影；图案完整停留后散成星点。点击处出发的新流星补上图案的一部分，完成后柔和闪光。

## 微缩世界

载体内有清楚的环境、建筑、居民或交通；几个主要地标、一条主要路线、一个正在发生的事件。适当放大，内部能看清。

6. **梦境之书**（`dream-book`）：打开的立体书，纸山、小屋、桥梁、河流、小居民、小船。书展开 → 地形立起 → 船出航、居民活动 → 天暗亮灯 → 旧景收回 → 翻页进入下一世界。点击先翘页再完整翻页，海港、山谷、星空小镇从书脊展开。
7. **瓶中潮汐港**（`bottle-harbor`）：横放的宽腹漂流瓶，薄玻璃内清楚展示海面、码头小镇、灯塔。涨潮 → 帆船进港 → 靠岸卸货箱 → 居民搬走 → 灯塔亮 → 离港退潮。点击瓶壁涟漪、鼓帆、灯塔朝点击方向照光。
8. **树洞四季镇**（`tree-village`）：树冠和树干，三层树洞小屋、层间升降篮、根部庭院仓库小路。春嫩叶 → 夏果实 → 居民乘篮搬果 → 秋落叶入库 → 冬窗灯积雪 → 春。点击落果、最近居民捡起搬回；冬季清扫积雪。
9. **星尘怀表城**（`pocketwatch-city`）：打开怀表内环形微城、外圈轨道车站、中心广场、下方转动齿轮。列车出站 → 经过车站运送光点 → 街区逐段亮 → 广场变灯 → 返回总站 → 下一轮。点击表冠转动、白昼转夜、车站窗灯依次亮，列车不停。
10. **云海旅行箱**（`cloud-suitcase`）：打开箱子、箱底云海、箱盖天空；三座浮岛有风车邮局、小屋、飞艇停靠点。邮局挂信 → 风车转、飞艇装货 → 穿云 → 到另一岛 → 信入屋、窗亮 → 返航。点击一封信落到邮局，飞艇接取后短途投递再回原航线。

## 机械与小伙伴

11. **发条机器人**（`clockwork-robot`）：方头圆身、短手脚、胸灯；眨眼、抬头、坐下晃脚、擦面罩、起身短走。点击先看向目标再挥手或点头，连续点击歪头疑惑。
12. **深海探测器**（`deepsea-probe`）：圆舱、双推进器、天线；浮沉、探照灯扫过、接近小光点观察再退回。点击朝目标倾斜、声呐、推进器气泡、恢复悬停。
13. **磁力积木伙伴**（`magnet-buddy`）：轮廓清楚的磁力积木角色、手能分离；搭拱门、叠高、再组回身体。点击吸来金属星，转动观察、抛起接住、放回。
14. **履带修补车**（`repair-rover`）：低矮履带车、折叠机械臂；小路巡逻、检查、修松动积木或小桥。点击机械臂伸向目标、敲两下拧一下、少量火花、完工亮灯收臂。
15. **风铃精灵**（`chime-spirit`）：风铃有双眼、风签小尾巴；闭眼摆、睁眼观察、大风抱住风签、风停放开。点击先看目标再摆，风签扬起、淡光波。

## 完整演出小游戏

自动运行、完成一轮、进入下一轮；无需用户接管操作；点击有实际短互动。

16. **星光打砖块**（`starlight-breaker`）：发球 → 撞砖反弹 → 裂纹/破碎消失 → 全清 → 下一布局逐块生成；漏接球消失再发。点击球短暂充能，下次命中明显碎裂后恢复。
17. **像素塔防**（`pixel-defense`）：怪沿完整路线进入 → 塔瞄准发射 → 弹丸命中消失、怪受击 → 击败碎光消失 → 波次结束再来。点击小范围防御脉冲，附近怪有明确影响。
18. **引力投星**（`gravity-star`）：弹射台调角 → 小星球发射 → 小行星附近弯轨 → 入接收站 → 接收站层层亮 → 换布局；失败落云回收重发。点击下一颗充能带尾迹，入站后亮灯、收拢、消散。
19. **迷宫寻宝**（`maze-treasure`）：入完整迷宫 → 走岔路、回退 → 找钥匙 → 开宝箱/出口 → 带宝离开 → 换迷宫。点击亮一小段正确路线，角色先看提示再探索；清楚开箱。
20. **矿车运星**（`star-minecart`）：矿口落星石 → 车接住下沉回弹 → 装满 → 去卸货站 → 倾倒入仓 → 空车返回。点击特殊星石落下，接住车斗亮，入库短星光。

## 共用要求与实现约定

- 保留像素/字符质感，轮廓先行；可混用不同大小像素簇、细线、稀疏字符与透明光感。
- 主体使用整个聊天区；历史会话沿用鲸鱼的透明叠加，不额外避让中央内容。不得铺不透明黑底。
- 主题配色与外观独立；跟随主题色，保留渐变、自定义方案、尺寸/速度/密度/透明度。
- 新类别支持按分钟同类轮换，保留用户手动固定；先前删除的五种动物不恢复。
- 点击背景触发场景回应；输入框有对应的轻反馈，焦点、草稿、选择和输入暂停保持正常。
- 新模块统一纯函数 `drawXScene(ctx, frame)`。`frame.time` 是引擎已控制的动画秒数，禁止自行 RAF/计时器/DOM 事件。
- 可选 `frame.reaction = { x, y, time, age, serial, burst }`：x/y 为画布归一化坐标，time 为点击时场景秒数，age 为已过场景秒数，serial 单调递增，burst 为短时连续点击数；无点击则 undefined。引擎仅保留最近事件，60 秒到期。反应应自行有始有终，不在过期边界跳场。
- `frame.reactions` 保留最近 60 个场景秒的已接受事件，最小间隔 0.25 场景秒、最多 256 条，供小游戏保持已发生结果。微缩世界在本次动作完成前合并重复语义点击，输入框和背景的轻量点击反馈仍正常显示；翻页或送信不会因连点被重启。
- `preview=true, time=0` 必须有完整可辨认首帧；生产卡片和背景用同一绘图代码。
- 转向不可通过横向压缩到零实现；保证所有姿态可辨认。
