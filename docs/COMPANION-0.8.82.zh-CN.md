# 鲸梦桌面伴随安装与验收

## 安装

1. 等正在运行的会话结束。在「插件 → 已安装」卸载当前的旧版鲸梦，保留 DSH 数据和偏好。
2. 在「插件 → 添加插件」选择 `dsh-whale-dream-0.8.82.tgz`，完成安装并立即启用。
3. 在 Windows 托盘右键退出 DeepSeek Harness，再重开。桌面左上角会出现灰白鲸鱼球。开关位于「设置 → 鲸梦主题 → 桌面伴随」。

## 操作和验收

| 操作 | 预期表现 |
| --- | --- |
| 鼠标移到鲸鱼球 | 边缘渐亮。按住时球体轻微收紧。 |
| 单击鲸鱼球 | 展开成胶囊，亮边短暂扫过。胶囊显示状态和当前可用的会话、模型、用量信息。 |
| 点击会话预览 | DSH 主窗口恢复。有可定位的会话时打开对应会话。 |
| 同时运行两条或更多会话 | 角标显示运行数量。点角标或胶囊里的「N 会话」打开浮层，滚动查看更多。点一行进入对应会话，也可点浮层右上角关闭列表。只要还有会话在执行，悬浮球就保持蓝色。 |
| 鼠标移出伴随窗口 | 开启自动收起时，约 1.25 秒后收起。也可再点鲸鱼立即收起。 |
| 在 DSH 发起会话并把主窗口收到托盘 | 执行时显示蓝色「思考中」。会话结束、停止或报错后，在没有其他执行中会话时恢复灰白「空闲」。 |
| 拖动悬浮球到屏幕另一侧 | 胶囊朝有空间的一侧展开。列表优先放在胶囊旁边，空间不足时换到另一侧或上下方。 |
| 右键关闭，或在托盘彻底退出 DSH | 悬浮球消失。右键关闭后可在鲸梦设置中再开启。 |
| 在「鲸梦主题 → 主题配色」切换深色、浅色或自定义主题 | 悬浮球、胶囊和列表即时更新底色、强调色与文字。思考中仍可通过蓝色识别。 |

收起球体直径为 38.5 个布局单位，约为上一版的一半。胶囊以会话标题为主，次行显示状态和模型，独立一行显示用量。浮层中每条会话的用量靠右排列，仍可直接点行跳转。当前 API 渠道有完整费用记录时使用原币种，估算值标为「约」。缺少完整费用时显示已记录的 Token，或已记录请求次数。尚无记录时显示「暂无用量」。账号余额和套餐总额度属于账户级数据。

## 设置

- 「显示桌面鲸鱼」控制是否显示窗口。
- 「自动收起」控制鼠标离开后是否收起胶囊和列表。
- 「动效强度」可选择标准或精简。精简保留两态配色，缩短界面反馈所需时间。
- 「显示会话标题与模型」关闭时，预览与列表显示通用会话名称，同时隐藏模型和用量。

## 本机性能测量

Windows 150% 缩放、DSH 运行时，分别测试点击鲸鱼展开胶囊，以及点击角标展开胶囊和会话浮层。每组包含 10 次展开和 10 次收起。

| 操作 | 绘制间隔样本数 | 绘制间隔 P95 | 最长间隔 |
| --- | ---: | ---: | ---: |
| 展开胶囊 | 500 | 17.69 ms | 20.43 ms |
| 展开胶囊和会话用量浮层 | 500 | 17.69 ms | 31.85 ms |

胶囊和会话浮层同时显示时，流光阶段单次绘制和提交耗时 P95 为 6.48 ms。窗口在交互、会话或主题变化时重画。Windows 动画效果关闭时，展开和高亮直接到达目标状态。

这些数据来自组件的绘制提交时间。显示器的实际呈现帧率和重负载下的表现尚未测量。可在 DSH 输出期间反复展开和收起，再检查托盘恢复与状态是否同步。

另在隔离的 DSH 0.2.2-rc.5 桌面环境中验证了安装、四项设置保存与退出清理。三条真实 DSH 会话同时运行时，宿主向悬浮窗发送的运行数依次为 0 → 1 → 2 → 3 → 2 → 1 → 0。运行数非零期间持续显示「思考中」。Windows 窗口测试也验证了列表滚动、翻页、自动收起开关、精简模式和行点击目标。已登录主窗口中的会话跳转需在安装后按上表验收。
