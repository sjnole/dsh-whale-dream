# Whale Dream 0.8.2 验证记录

## 范围与结果

用户最终圈定的美术重做范围是「星空与光影」「微缩世界」「完整演出小游戏」，各 5 项，共 15 项；「机械与小伙伴」适度细化，重点机器人。原海洋、经典五款游戏与植物美术保留。本轮同时修复新会话缩小、历史会话全屏导致的主体尺寸不一致。

完整 `npm run check` 已通过：TypeScript 类型检查、生产构建、独立 HTML 导出，以及 **384 项测试，384 通过，0 失败，0 跳过**。测试运行耗时约 117.4 秒；记录日期 2026-11-14。

完整 gate 输出见 `test-results.txt`。官方接口基线继续为 DSH `dsh-v0.2.2-rc.3`，原版 Dream Skin 11.7.0、ASCII Whales 0.1.6 与 SJ 0.1.4 的来源和许可证保留。此前验证记录见 `VALIDATION-0.8.1.md` 与 `VALIDATION-0.8.0.md`。

## 尺寸与位置修复

0.8.1 把输入框上方的可用高度传给所有绘制器，主体、字形、棋盘和内部细节随之缩小。这是产品行为错误。原测试中的「所有像素必须在输入框上方」也编码了这个错误目标，已被明确替换。

0.8.2 的规则：

- 新建和历史会话始终使用同一完整窗口宽高，点击坐标与游戏逻辑坐标不改写。
- 输入框只影响主体的纵向位置，不能改变主体 scale、横向路径、场景数量或游戏棋盘。
- 以脸部、花冠或内部故事区域作为焦点，尽可能向上平移；大载体可局部经过输入框后方。不会为了「全部无遮挡」把整个世界缩成小图。
- 拟合尺寸与实际载体边界分别处理，避免把留白也算成物体而限制平移；核心轮廓在视口内保留。
- 新旧会话有相同的外围内容与巡游路径。历史正文依旧使用既有透明度和淡化规则；外观的实际尺寸不变。
- 模式切换在同一引擎、时钟与 session 中进行，焦点位移柔和过渡；减少动态模式直接应用布局。
- 删除「上方放不下就跳到下方」的硬分支；横向和纵向重叠权重均连续。发现过输入框 top 从 233px 到 234px 导致机器人跳 342px 的问题，已修正并加入专门回归。
- 输入框增高或位置改变时，按主体保留位移并在原有动画帧内缓动，设定每秒最大移动距离；布局时间独立于用户设置的动画速度。花丛曾出现输入框底边移动 1px、主体目标移动 15px 的高增益情况，现已加入实际逐帧回归，避免目标连续却画面抽动。
- 改变外观大小或窗口尺寸后，旧缓动位移会立即按当前主体边界重新约束，不把旧负位移带到新画面而使角色头部出屏；保留用户新尺寸、原场景与原有边缘裁切规则。
- 只有整个视口都被前景输入框覆盖时才暂停场景；局部被盖住不会缩小画布或清空游戏进度。

## 真实执行的专项检查

- 20 个主体型外观在多个视口、同时间、同用户大小设置下，hero/chat 的 scale 完全一致，横向位置和物件数量一致。
- 30 个非海洋外观仅切换会话 phase、输入框位置影响为零时，生产 Canvas 像素完全相同；主机前景与历史阅读遮罩另计。
- 10 个游戏同一 session 的 hero → chat → hero 保持状态、事件、时间与像素一致；实际窗口 resize 仍按既有规则保留当前局。
- 微缩世界原故事和连续性检查保留：翻页保留、居民、投递、货物交接、历史清理不撤销已发生结果。
- 小伙伴保留连点事务、表情过渡、机械臂与转向连续性；75 秒 × 60 Hz 漫游检查输入框重叠边界；另有输入框单像素移动回归。
- 共享布局验证输入框单像素移动、离散高度变化与新旧会话切换：不重建场景，不重置时间，不改变 scale，位移逐帧收敛。
- 星空保留连续点击、轨道、星图生成/消散边界、星云出生循环、纹理/配色/大小和宽窄屏检查。
- 游戏保留真实碰撞、命中闪白、爆炸消失、砖块移除、接收、开箱与卸货检查，没有降低旧断言阈值。
- 主题、渐变、自定义方案、分钟轮换、输入框点击反馈、隐藏/离屏/输入暂停/减少动态、卸载与 SJ 原交互继续进入统一 gate。

## 性能与图片证据

`qa/review-0.8.2-games/native-timing.json` 记录实际生产绘图的连续采样：每款 12 秒、30/60 Hz、每秒 5 次点击，第 6 秒切换会话模式。最终顺序测量的 60 Hz p95 绘制耗时：打砖块 1.55ms、塔防 2.32ms、引力 1.39ms、迷宫 1.58ms、矿车 4.09ms。迷宫墙面采用有界几何缓存与按材质批量绘制，减少新增细节的开销。此处是作者环境 Native Canvas 计算时间，不能当作 Windows DSH 帧率。

审查目录：

- `qa/review-0.8.2-celestial/`：五项生产画面前后对比。
- `qa/review-0.8.2-micro-worlds/`：五项本体前后图、旧 hero / 新 hero / 新 chat、模式几何。
- `qa/review-0.8.2-companions-plants/`：机器人材质、伙伴调整、同尺寸模式图、植物未改美术证据。
- `qa/review-0.8.2-games/`：深浅主题前后图、真实互动分镜、状态与像素连续性、原生计时。
- `qa/review-0.8.2-composition/`：30 项新旧会话全尺寸构图，含历史淡化和输入框示意；三类代表旧版/新版比较。

图像均由真实生产绘制器生成；编辑器框与正文是位置示意，**不是浏览器或 DSH 实机截图**。其中明确标注 renderer 的旧图是在相同全窗口坐标下比较美术；明确标注 compressed stage 的旧图运行完整 0.8.1 构图入口。

## 交付与限制

0.8.2 HTML 与 TGZ 嵌入同一客户端 bundle，打包核对脚本内容与哈希；完整 ZIP 包含源码、安装包、预览、测试和上述审图记录。旧版静态 HTML 不会自动变成新版，应重新下载或刷新当前预览并检查顶部版本。

尚未在用户 Windows DSH EXE 中安装运行，未做真实浏览器/GPU 合成验收。输入框占据主要位置时，大载体下部或局部近景仍可能在其后方；本轮明确优先同尺度和可辨认焦点。实际窗口长宽变化时，进行中的棋盘可能暂时留白，下一局采用新比例，以保留当前进度。
