## 星空与光影

`celestial.mjs` 使用同一场景时钟和透明 Canvas 绘制。星环分前后两层遮挡、卫星有实际轨道；极光分层流动；星云聚散和光核；棱镜折射光束；流星形成帆船、山峰、鲸影后解散。

专项验证真实点击改变像素、动作结束归于平稳、三种星图的形成/停留/解散阶段、长时间有限状态、深浅主题与宽窄背景。独立审查修复并回归：

- 连续点击累计尚未完成的额外卫星圈数，不让卫星突然回到旧相位。
- 390×740、最大大小下按完整旋转轨道和卫星外轮廓约束，不让卫星裁出画面。
- 点击流星按点击时刻冻结目标点；自动星图进入下一条边或下一图案时，不改变正在飞行的目的地。
- 棱镜随二维点击方向倾斜；大小 1.3–1.6 仍有效，使用几何边界适配而非任意截断。

## 机械与小伙伴

`companion-state.mjs` 提供姿态与关节，`companions.mjs` 绘制主体和回应。机器人观察、坐姿、擦脸、步行与挥手；探测器接近光点、扫灯、声呐和气泡；积木伙伴从自身拆出积木搭拱门/塔，再归位；履带车检查桥、伸臂敲击与修补；风铃的眼神、抱风签和分层摆动。

专项检查首帧轮廓、多动作周期、真实点击、固定机械臂段长、无横向压扁、互动结束衔接、全范围参数、360×760 与 1600×360 最大尺寸边界。实际截图审查后修正擦脸手的前后层级与修补车折臂遮脸。共享引擎另验证最慢速度下连续点击表情仍可触发。

## 公共绘制、点击与生命周期

- `appearance-render.test.mjs` 明确覆盖全部 30 个非海洋生产 renderer：实际像素、不同像素簇尺寸、透明度、中心使用、深浅主题、320×180 卡片、390×740 窄会话、字体覆盖与 Canvas 状态恢复。颜色、颗粒、大小、密度、时间与三种纹理都须产生实际变化。
- 所有卡片调用与背景相同的 `drawAppearanceFrame`；不以单独近似图标代替正式外观。海洋 8 项仍走原字符 renderer。
- 新外观不铺不透明全屏底板，主题渐变透出。历史会话使用鲸鱼同一可见度和正文淡化；没有中央避让禁区，也不将主体全推到角落。
- 点击短反馈共 31 种实际几何，覆盖 38 项外观；最多 4 个同时存在、100ms 节流、到时清理，明暗和主色适配。
- 场景事件由唯一引擎时钟驱动，最小 0.25 场景秒间隔，保留最近 60 场景秒，上限 256 条；微缩世界按本次完整事务进一步合并忙碌点击。不会引入第二套 RAF。
- 背景空白和可编辑输入框支持点击。SVG 透明局部层不抢事件，消息、代码、链接、按钮、菜单、圆环、其他会话、只读和禁用输入区排除。焦点、选区、草稿和滚动保留。
- 输入暂停不推进场景，也不接受背景语义动作；输入框仍有短暂局部反馈。隐藏、离屏、系统减少动态、零尺寸、关闭及卸载继续停止或清理动画。
- 重复切换 38 项复用一个装饰 Canvas，保持消息树；销毁释放观察器、定时器、事件历史和监听。低速连点与超过事件缓冲总量的长期点击有实际引擎回归。

## 设置、保存、轮换与原功能

- 首页保持「主题配色 / 外观与动态」，七类按钮按宽度换行；当前新增外观有具体点击说明。沿用大小/速度/丰富程度等公共参数，没有二十组专用设置。
- 默认主题只改变主题配色、背景与材质；不更换用户外观。新增 20 个 ID 均经过完整方案保存、重开与恢复，四个新类别各自的自动轮换和未修改标记也已检查。
- 分钟间隔仍为 1–10080 整数、新配置 60，旧每日偏好迁移 1440；启用/改间隔/应用自动方案重新计时，错过期限只补换一次，手选卡片改回固定。
- 最终 HTML 在 JSDOM 中执行实际 React 与生产 bundle：遍历全部 38 卡片，检查四类说明，执行背景和输入框点击、保存、重新加载、失败重试与卸载。不是仅搜索文件字符串。
- 统一下拉、8 套原主题多层渐变、2–8 色自定义排序、15 项语义配色、图片与材质、30 份完整方案、2 MB 边界及有序保存桥继续回归。
- SJ 0.1.4 的模型、推理等级和团队交互保留；外观操作不写这些业务状态。侧栏单图标和移除维护页保持。
