# 鲸梦 0.8.44 — 启动屏卡顿优化与放大验收

## 基线与变更范围

从用户此前上传的 0.8.41、逐次修订后的 0.8.43 可安装插件包继续补丁；只修改启动脚本、共享客户端早期 IIFE、Host 资源 URL、启动资产及版本/验收文档，其他业务 UI、信息栏、主题预设与插件配置不动。

## 动画性能处理

- **主路径**：将 106 帧透明 WebP 动画（1,290,814 B）离线重新采样为 24fps、137 帧、5.708s、H.264 768×432 MP4（370,234 B），主资源按需下载缩小约 71.3%。保留预渲染代码字符鲸鱼与原动作时间线，视频底色以 screen/multiply 合成，暗主题浅色字符、浅主题深色字符。H.264 在具备支持的 Chromium/Electron 平台可通过浏览器媒体解码及合成通道播放；是否真正硬件解码由用户设备驱动决定。
- **动画时序**：Logo、鲸梦与六字文案仍为 350 / 1090 / 1750 / 2470 / 3300ms 起始，改用 CSS opacity / transform keyframes，无启动期阶段性 setTimeout；降低 DSH JS 主线程繁忙导致回调堆积、动画阶段突然跳变的风险。
- 移除动画期间的 filter / text-shadow 动态过渡；保留静态阴影作为文字对比度保护。主题观察器只监听 body 主题标记，减少初始化时不必要的 style 属性变动回调。
- H.264 不可用、播放失败或资源错误时自动降级到原 0.8.43 WebP；第二资源也不可用时仅显示品牌，不阻塞 DSH。保留低动态效果、Esc/背景点击跳过、单次启动及 7s 自动退出。

## 新视觉规格

- 标题改为「鲸梦 探索未至之境」，不再存在 `×` 或 separator DOM。
- 启动品牌组合仍水平垂直居中、Logo 在前、名称及六字标题依次显示。
- 鲸鱼宽度由 `min(90vw,144vh,1600px)` 改为 `min(112vw,178vh,2080px)`，中心 y 从 57% 调至 60%，位置在品牌后层。**1280×720 视口**：0.8.43 约 **1037px** → 0.8.44 约 **1282px**，增大约 **23.6%**。1920×1080 同比例约 1555px → 1922px。

## 已执行测试（非 Windows DSH 实机）

1. `npm run prepack` 通过：Index / Client / Boot / Host / Atlas 语法检查。
2. `npm test` 19/19 个代码专项断言通过（新视频及回退、资源导出、原始 Logo path、文字时序/居中/无 ×、主题、关停、Host Desktop/Web 注入、客户端字节一致性等）。
3. 独立 Chromium 播放：视频 `readyState=4`、`currentTime` 连续增长，`data-wd-whale=native-video`；页面无异常或资源错误。
4. 浅色图像 `filter:invert(1);mix-blend-mode:multiply`，深色 `none;screen`，品牌文字配色正常；1280×720、1920×1080、320×640 居中正常。
5. 模拟 DSH 启动主线程同步占用 2500ms 后，视频进度约 2.5s，CSS 文字状态对应 2.5s，说明时序不再依赖各阶段 JS timeout；此为模拟负载，不是 DSH 实机 fps 结论。
6. MP4 故意损坏时自动显示 WebP，Esc 后覆盖层被清除；`prefers-reduced-motion:reduce` 时不加载媒体，1.3s 自动退出。

## 尚待用户 Windows DSH 实机检查

- 原生 Host 插件 `plugins/dsh-whale-dream/assets/*.mp4` 静态路由及 MIME（不支持 MP4 时自动 WebP 回退）。
- 实机冷启动期间是否仍有明显卡顿、掉帧及设备 GPU 软硬件解码差异。仅凭浏览器验证不能保证所有 Windows 设备零卡顿。
- 先前宿主整体动画由其他插件造成的线程争抢，不归此插件控制。本轮避免本插件自身继续成为明显瓶颈。
