# Whale Dream 0.8.36 · Brand startup hotfix / 验证说明

基于用户上传的 `dsh-whale-dream-0.8.35.tgz` 编译包修改。仅修复启动屏：没有原始项目完整 TS 源码，不声称做了全量重建。

## 变更

- 采用纯 SVG（`currentColor`）鲸梦鲸鱼形状，去除内嵌 PNG 以及 icon.svg 原有圆角背景。
- 标题仅包含「鲸梦 探索未至之境」，没有「×」。
- 0.3s Icon 出现；0.6s「鲸梦」出现并将 Icon 平滑让位；0.94s「探索」、1.34s「未至」、1.74s「之境」分别从遮罩下方浮现；2.71s 开始退场，约 3s 清理。
- 在启动 React/DSH 插件加载前运行，原生 DOM/CSS 实现 React Bits RotatingText **类似的字形遮罩和上滑效果**，没有打包 React/motion 或第三方字体。
- 主题的背景渐变仍取 Host 注入，按自定义渐变的中心色估算文本对比色；浅色/深色自动使用深/浅字符颜色。Icon、标题共用 `currentColor`。
- 退出释放样式、定时器、监听器和主题观察器。减少动态效果时直接出现最终标题并短暂留存。
- Host 关闭开关后不注入启动播放器；客户端 fallback 含相同脚本。
- 0.8.35 中原生窗口控制区、信息栏、圆环、日常外观等相关内容不变。

## 测试

- `node --check`：`lib/startup/boot.js`、`lib/client.js`、`lib/startup/host.mjs`、`lib/index.js` 语法通过。
- `node --test docs/qa/smoke-0.8.36.mjs`：**16 / 16** 通过。
- Chromium（headless，真实 Host 注入预览）功能检查：**15 个**项目通过，包括阶段出现、退场清理、鼠标跳过、Esc、开关立即关闭、减少动态、5 套深浅/渐变代表主题。
- 浏览器截图：1366×768、1920×1080、560×700 都无图标底板，主标题可读，整句正常出现且自动退出；另外检查明亮和极光渐变。
- 源码一致性：Host 加载的 `boot.js` 与 `lib/client.js` 中回退启动脚本逐字节一致。

## 未做 / 局限

- **未做 Windows DSH EXE 实机验收**，不能承诺所有原生标题栏细节已验证。
- **未执行 38 种动态外观、SJ 圆环及所有服务商信息栏的完整功能回归**；上传包不含全量 TS 原始源码和原始测试集。
- 渐变颜色判断使用中心颜色近似；极端多色/图片壁纸可能需要实机人工检查字体对比度。
- 更改了启动屏所需的已编译分发代码，不应视为原始项目内对应源码的提交。若有完整项目源码，应将同样修改回迁至项目启动源文件和构建流程。
- 当前独立预览的「重新播放」仅供展示；生产安装不会给用户增加额外设置入口。

## 升级

备份 `~/.dsh/whale-dream.json` 及信息栏账本，卸载旧版同名插件后安装 `dsh-whale-dream-0.8.36.tgz`，彻底退出 DSH 重新启动。旧版 0.8.35 TGZ 可用作回滚。
