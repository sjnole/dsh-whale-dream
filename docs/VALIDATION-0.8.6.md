## 已验证的行为

### 常显和操作方式

- 默认自动适配，按实际账户数据选择余额、额度、账单、已知参考价或真实用量；没有余额接口不出现空余额占位。
- 自选保留 14 项勾选排序。切回自动不会覆盖手动列表；再次切回自选可恢复。旧默认迁移为自动，既有自选、主动清空和关闭状态保留。
- 常显以图标与数值为主。费用保留会话／今日／30天／累计短范围和 `≈`，参考单价保留 `/百万`；完整说明支持悬停、聚焦和详情入口。
- 额度、缓存与上下文显示小比例图，真实 `0%` 保留；没有数据或分母时不画假零。
- 在显式模拟的宽度变化下，仅将放不下的末尾字段收进 `+N`，恢复宽度后重新显示，配置顺序不改变。测量和可见内容使用同一个组件。
- 信息栏使用原生输入工具区，位于 SJ 圆环左侧；切换新／历史会话保留输入草稿。弹层使用 body portal，Escape 关闭后焦点回到入口，卸载清理订阅与弹层。
- 三个同级设置页保持独立，主题切换不覆盖信息栏显示方式或顺序；原作者署名和链接保留。

### 当前时段和价格

- DS 常显与详情头部只有一个当前状态，以及距明确相反时段的倒计时。缺失或同态的下一状态不产生倒计时。
- 完整日程和两档参考价默认折叠；仅当前适用列突出。跨边界、跨北京时间日期或未知日历时不将旧参考价视为当前适用价。
- 共享北京日历覆盖 2026、2027 年，核对工作日时点、周末、法定节假日和调休周末；当前不确定时段没有推断价格或虚构下一次切换。
- 官方 DS 同名模型不会让未知第三方网关继承官方价格。Ark 明确收录的模型保留自身参考时段，在单价项显示；没有 DS 官方身份标识，跨日旧快照显示待更新。
- 边界刷新复用已有轮询计时器，不强刷远端账户接口；失效边界不形成零间隔重试。窗口隐藏暂停，恢复可见后核对数据。

### API、订阅和云账单

- 通过当前模型目录切换实际生产组件：官方 DS、普通 OpenAI API、同名模型自定义网关、订阅和 AWS 云账单分别按真实能力样本选择内容。
- 无余额接口的普通 API 显示已有参考价与用量；无单价网关保留真实 token 和未计价状态，连指标都没有时才退回当前模型入口。
- 订阅保留 `five_hour`、`seven_day`、月度等实际窗口，主要窗口可同时常显，详情保留其余窗口与重置时间；上下文缺失时可回退真实 token。
- Command Code 同时返回额度窗口与 credits 时保留两者。GLM 余额没有声明币种时不猜 CNY，真实零保留。
- AWS 月度账单、Fireworks 周期 tokens、Cloudflare requests 和免费剩余额度 `0` 的单位与周期保持区别。
- 智谱国内与国际使用独立请求源和缓存，并读取对应凭据与域名；缺 Key、查询失败或无套餐时不跨区借用另一账户或转发凭据。
- 真实余额、云账单与本地费用估算明确区分；本地汇总可能包含实报金额和参考估算，不能宣称是服务商最终账单。

### 趋势、账本与稳定性

- 每日图表按实际日期保留横轴缺口，CNY 与 USD 分别缩放且不换汇；真实零、未计价、部分计价和无记录各自保持语义。
- 图表可切换币种，支持左右方向键、Home / End 日期选择，并提供可展开数值明细。输入／输出比例仅在两者均有效且总量大于零时显示。
- 会话、模型、账户缓存隔离，去重请求；晚到响应不串入新选择。刷新失败保留同一来源的有效旧数据并提示未更新。
- 使用真实 SQLite worker 验证独立账本、四档汇总、滚动边界、子代理归属、流结束记账、CSV / JSON 导出和持久清空。生成中拒绝清空，确认成功回执后才报告清空完成。
- 固定上游源码逐文件 SHA-256 校验通过，适配在鲸梦自有代码中完成，MIT 原文和版权声明保留。

## 验证边界

测试运行于 **Node.js v24.22.1**。DOM 交互使用 JSDOM、明确的模拟宿主和账户，宽度来自显式模拟尺寸；SQLite worker 是真实实现，账户接口响应是离线 fixture。**本轮没有启动浏览器，也没有在用户的 Windows DSH 或不同配置电脑上进行真实视觉／性能验收。** 这些检查不能替代实际安装后的视觉验收，也不证明每家服务商的真实账户接口此刻可用。

没有重复运行未改动的全部 38 种外观或旧性能矩阵。0.8.3 的历史性能报告与测试计数不计为本轮实测；本版重新导出的性能自检 HTML 可在目标电脑上运行，但不等同于完整 DSH 的真实负载。上一版记录保留在 [VALIDATION-0.8.5.md](VALIDATION-0.8.5.md)。
