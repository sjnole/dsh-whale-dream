本轮没有重复执行全部渲染器和性能测试；0.8.3 的 419 项全量检查记录另存于 `docs/test-results-0.8.3.txt`，不计为本轮重新通过。

## 交互与保存检查

- 推荐主题页、我的方案列表及外观页不再渲染保存区；创建入口仅位于「我的方案」。
- 原调整页标题变为「创建新主题」，返回明确落到「我的方案」。
- 创建页保留名称输入与「保存方案」，捕获当前完整搭配；已有自定义主题处于使用中时也始终创建新 ID，不覆盖原方案。
- 同名校验保留已填名称；保存成功后返回我的方案并显示创建结果。
- 创建表单在不可见时不输出 DOM，同一设置窗口内保留名称草稿与失败创建 ID，切到外观页再返回可继续。
- 保存进行中离开创建页，完成后不强行跳回列表；退出设置窗口后的异步完成不回调旧界面。
- 首次创建失败后可重试同一记录；隐藏表单期间从首页重试成功后清理失败标记，下一次创建产生新记录，避免改名或复用上一份主题。
- 已有方案的「保存修改」移到当前已修改方案卡片的「管理」内，点击时再次核对当前方案 ID；重命名、删除和恢复操作保留。
- 继续通过现有完整方案流程核对渐变、配色、海洋/游戏/植物、分钟轮换及圆环偏好的保存和恢复，主题创建不向模型或推理接口写入业务设置。
