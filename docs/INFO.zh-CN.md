# 鲸梦 0.8.7 信息栏使用说明

信息栏位于**输入框内 SJ 推理圆环左侧**，新会话和历史会话使用同一位置。默认使用 **自动适配**：根据当前接入实际返回的数据，显示最有用的余额、额度、计价时段或用量。点击信息栏，详情向上展开。

设置入口是 **设置 → 鲸梦主题 → 信息栏**，与「主题配色」「外观与动态」同级。信息栏的开关、勾选和顺序独立保存，切换主题或使用自定义方案时保持原样；颜色随当前鲸梦主题适配。

## 选择常显内容

在 **设置 → 鲸梦主题 → 信息栏** 选择显示方式：

- **自动适配**：跟随当前模型及账户能力选取有实际数据的内容，不需要逐项配置。没有余额查询接口时，不把空余额放在常显区。
- **自选常显**：固定使用自己选择的内容。勾选项目后，用右侧 **↑ / ↓** 排序；展开 **添加常显内容** 可继续添加。

切回自动适配不会删除自选内容和顺序；再次切回自选时恢复原搭配。**恢复默认** 会恢复自动适配及初始自选搭配。信息栏开关和偏好独立保存，切换主题不会改变它们。

### 自动适配如何选择

| 当前接入及实际数据 | 优先常显 |
| --- | --- |
| DeepSeek 官方、适用峰谷模型 | 查到的余额、当前计价时段与下一时段倒计时、已有会话费用估算。 |
| 其他有余额接口的 API | 真实余额、已知模型参考单价、已有会话费用估算。 |
| 返回订阅额度的账户 | 最多两个主要额度窗口及剩余比例，配合可取得的上下文或 token 用量；更多窗口在详情中。 |
| 云账单账户 | 服务商返回的月度或周期账单／用量，保留实际单位；另有本地会话费用记录时显示估算。 |
| 没有余额查询的普通 API | 已知参考单价、已有会话费用；缺少单价时显示可确认的 token 或上下文。 |
| 无已知价格的自定义 API | 可确认的 token 或上下文；连这些数据也尚未取得时才以当前模型作入口。 |

判断依据是账户数据和模型价目，不是只凭模型名字猜平台。订阅额度不会自动换算为额外应付费用；普通 OpenAI API 不会被当成 Codex/ChatGPT 订阅。日期和时钟不自动加入，需要时可在自选常显中开启。

信息栏会利用 SJ 圆环左侧的整段剩余宽度，保留输入框原有的控件。**只有实际放不下时才出现 `+N`**，表示还有 N 项被收起；点击信息栏仍能查看详情。它按内容的实际宽度展示所选项目，不限制为固定两项。

全部取消勾选后仍保留信息图标，点击可看详情。关闭 **显示会话信息** 会隐藏入口，但保留显示偏好和账本；只要鲸梦仍启用，后续观察到的模型用量仍会记录。

### 常显如何阅读

常显按内容使用 **图标＋数值** 或 **短文字＋数值**，两种识别方式不重复叠加。余额保留钱包图标和金额；费用删除图标，只保留「会话 / 今日 / 30天 / 累计」短范围与金额，其中「会话」表示整段会话的已记录费用，不是单次调用费用。模型名称、时间、日期和已有方向箭头的 token 不再附加装饰图标。

本地费用与趋势合计保留 **≈** 标记，表示统计可能包含服务商上报金额与参考价估算；它们不等同于账户正式账单。模型参考单价常显使用 **≈、输入输出箭头及 /百万**，删除价格图标与重复的「参考」字段；完整参考价说明在悬停与详情中。

额度保留 5h、7d 等窗口短标、比例图和百分比，删除额外额度图标。缓存和上下文保留区分图标，将细比例条放在数值下方，不增加横向占位。真实的 0% 保留，缺少数据时显示 `—`、不画假零。鼠标悬停可查看完整文字解释；键盘聚焦信息入口可读取完整说明，按 Enter 打开详情。

有内容可见时不重复显示最左侧总统计图标。全部取消选择或空间不足以显示一个完整字段时，保留可点击图标入口，完整数据仍可展开查看。

新版偏好格式为 v4。旧版使用初始默认组合时升级为自动适配；旧版改过的选择和顺序保留为自选常显，主动清空的列表仍为空，关闭状态也保留。不会向已有自选组合强行补入 DS 项。非适用模型会隐藏 DS 项且不留空位。

### 14 项可选内容

| 项目 | 显示什么 |
| --- | --- |
| 当前模型 | 当前会话的服务商与模型。 |
| 余额或额度 | 按当前服务商显示余额、订阅额度或云账单摘要。 |
| DS 高峰／空闲 | 适用 DeepSeek 官方模型的当前计价时段及距相反时段的倒计时。 |
| 模型单价 | 每百万 token 的参考输入与输出价格；明确提供峰谷参考价的其他平台模型另附当前时段。 |
| 本会话费用 | 当前会话已记录的费用估算。 |
| 今天费用 | 当前账户今天的费用估算。 |
| 近 30 天费用 | 当前账户滚动近 30 天的费用估算。 |
| 累计费用 | 当前账户自鲸梦开始记录以来的费用估算。 |
| 输入与输出用量 | 宿主提供的当前会话 token 用量。 |
| 缓存命中率 | 宿主提供的缓存读取量占输入用量的比例。 |
| 输出速度 | 根据宿主返回的输出 token 和生成耗时显示 token/s。 |
| 上下文占用 | 宿主提供的上下文用量与模型容量。 |
| 当前时间 | 当前设备的本地时间。 |
| 当前日期 | 当前设备的本地日期。 |

自动适配会跳过无法取得数据的项目；自选项目尚未取得数据时保留未知说明。模型尚未同步、服务商没有接口或宿主没有提供对应字段时，不拿另一个会话的数据补齐；没有余额查询接口也不表示该模型无法使用。

## 点击后能看到什么

### 账户信息

信息随当前会话模型的服务商切换，按实际取得的数据展示：

| 账户类型 | 详情 |
| --- | --- |
| 余额账户 | 可用余额；接口返回时另列充值余额和赠送余额。 |
| 订阅账户 | 当前套餐、各额度窗口的剩余比例与重置时间；取得到期时间时一并显示。 |
| 云账单账户 | 服务商返回的当期账单；接口提供时补充预算已用比例、免费额度和重置时间。 |

同一订阅返回多个额度窗口时，详情会逐个显示，包括实际返回的 5 小时、7 天、月度等窗口及各自重置时间。只查到套餐名称而没有额度窗口时，只显示已有信息，不补造 0% 或 100%。账户返回 credits 时保留 credits；未声明金额单位时提示单位未返回，不自行认定为人民币。云账单按真实来源区分本月／本周期，并保留用量单位及来源说明。普通 OpenAI API 没有可查询的真实余额时，也不会显示一个假定的起始余额。

点击面板中的 **刷新** 可以重新查询。查询失败时保留上次有效结果，并提示未更新；不能把旧结果当作刚查询到的新余额。切换会话或模型后，数据仍按当前会话和所选服务商分别读取。

### DeepSeek 高峰与空闲

常显只显示**一个当前状态和距下一状态的倒计时**：

- 当前为高峰：**高峰 · 1h20m后空闲**。
- 当前为空闲：**空闲 · 3h10m后高峰**。

以上时长仅为说明格式，实际按当前时间计算；`h` 是小时、`m` 是分钟。常显省去 DS 前缀及日月图标，完整中文倒计时和 DeepSeek 身份仍在悬停与详情中。不会把高峰和空闲作为两个同时生效的状态并排显示。这里表示计价时段，不能用来判断服务器负载、响应快慢或排队程度。

展开详情后，首先看到同一个当前状态和下一次变化。完整说明收在 **时段规则与参考价** 中，包含：

- 当天北京时间 **24 小时时段条**，标出当前时点；高峰使用不同纹理，避免只能靠颜色区分。
- 下次切换的**具体日期、时间和剩余时长**，跨周末或假期时仍标清日期。
- 输入缓存命中、输入未命中、输出三种单价的**空闲 / 高峰对照表**，突出当前适用列。
- 官方价格来源和本版核对日期；未取得或过期的时段显示待确认 / 待更新。

截至本版核对日 **2026-11-15**，DeepSeek 官方规则是北京时间周一至周五、排除中国法定节假日，**09:00–12:00、14:00–18:00 为高峰**；其余时段及周末、节假日全天为空闲。调休上班的周末仍遵循官方“周末全天空闲”的规则。来源：[DeepSeek 官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

内置价目与当前官方说明一致，单位为**人民币 / 百万 token**：

| 模型与时段 | 缓存命中输入 | 未命中输入 | 输出 |
| --- | ---: | ---: | ---: |
| Flash · 空闲 | 0.02 | 1 | 4 |
| Flash · 高峰 | 0.04 | 2 | 8 |
| V4 Pro · 空闲 | 0.15 | 4.5 | 13.5 |
| V4 Pro · 高峰 | 0.30 | 9 | 27 |

这些是固定版本的参考价；服务商价格可能变化，实际账单以服务商为准。官方 Flash 的已确认兼容模型名按同一来源处理；第三方网关即使模型名字相同，也不会因此套用官方 DS 状态和价格。已明确带有服务商来源的价目条目按其自身规则处理。

原插件价目中明确收录的火山 Ark 两款模型（`deepseek-v4-1-flash-261017`、`deepseek-v4-1-flash-economy-261017`），在 **模型单价** 项中保留其参考计价时段、下一次切换和峰谷参考价格。它们不是 DeepSeek 官方账户，不显示 DS 官方徽标或日历。其他平台的固定参考价也不代表平台当前实际结算价；自定义网关没有明确价目时保持未计价。

本版固定日历覆盖 **2026、2027 年**，分别核对了 [2026 年国务院通知的北京市政府转载](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html) 与 [2027 年通知的人社部转载](https://chinajob.mohrss.gov.cn/h5/c/2026-11-09/635850.shtml)。超出覆盖范围时，如果是否属于假期会影响价格，显示时段待确认，不推断当前价格或编造下一次切换。已明确的服务商实扣金额仍可记录。

信息栏和账本共用同一日历。接近切换边界时，已有轮询会提前到边界刷新；窗口隐藏后暂停，恢复时重新核对，避免后台持续高频查询。

### 费用估算

费用详情固定分为四档：

| 范围 | 统计口径 |
| --- | --- |
| 本会话 | 当前会话在当前账户下的已记录调用；宿主能提供关联信息时，包括其明确关联的子代理。 |
| 今天 | 当前账户按北京时间当天累计的记录。 |
| 近 30 天 | 当前账户从当前时刻向前滚动 30 天的记录。 |
| 累计 | 当前账户在这份鲸梦账本中的全部记录。 |

面板显示真实的**统计开始时间**。安装之前的调用、鲸梦停用期间的调用，以及宿主没有上报的用量，都不能仅凭打开历史会话补算出来。

人民币和美元分别展示，不进行汇率换算。服务商明确报告金额且币种可确认时记录该金额；其余可计价模型依据随本版固定的参考价格计算。未知价格保留 token 用量，并显示 **未计价** 或未计价记录数。没有记录显示 **暂无记录**，不会显示成已经核实的零费用。

展开 **参考单价与计价说明** 可看当前所选模型的输入未命中缓存、输入命中缓存、输出三项参考单价；它不是将全部历史记录改按当前单价重算。每日费用使用柱形趋势图；有多个币种时可切换，各币种使用独立刻度，不叠加或换算。鼠标悬停或使用键盘左右方向键可查看具体日期，Home / End 可跳到首尾。圆点表示真实零费用，菱形表示仍有未计价记录，空白表示没有对应币种的已计价记录；不会把缺失或未计价的日子补成零。展开 **按日查看费用明细** 可看原始日期、金额和未计价数量。参考价目随鲸梦版本交付，费用估算以服务商实际账单为准。

这里的「今天」和按日记录使用 `Asia/Shanghai`（北京时间）；常显的时间与日期使用当前设备时区，二者在跨时区使用时可能不同。

### 会话用量

面板还汇总宿主提供的上下文占用、输出速度、输入输出 token、缓存读取、缓存命中率和对话轮次。输入与输出另用比例条表示；只有两者都有有效数据且总量大于零时绘制。上下文细分仅在宿主提供相应字段时显示。

本会话费用可包含明确关联的子代理，而宿主原生用量字段可能只覆盖当前主会话，因此两处 token 数不一定相同。信息栏展示现有统计，不新增模型选择器或第二个 SJ 圆环。

## 导出和清空记录

打开 **设置 → 鲸梦主题 → 信息栏 → 统计记录**：

- **导出 CSV**：便于用表格软件查看调用记录。
- **导出 JSON**：保留结构化字段，便于留档。
- **清空记录**：先显示确认，再删除鲸梦的全部本地统计记录。正在生成回复时不能清空，请等待结束。

导出记录包含调用时间、服务商、模型、会话标识、token 与计价信息，不包含聊天正文或密钥。不同币种保留在记录的币种字段中，不换算成同一个金额。

清空不可撤销，需要留档时先导出。清空只处理鲸梦账本，不删除服务商的正式账单，也不清除主题方案或 DSH 账户凭据。界面没有确认成功时，请先刷新检查结果。

## 账户与额度配置

默认复用 DSH 已配置的账户、模型凭据与可用登录状态。只有无法读取额度时，才需要展开 **信息栏 → 账户与额度配置**。

阿里云 Token Plan 的账户查询可能需要额外的 AccessKey ID 与 AccessKey Secret。这里仅提供这两个必要输入，保存后交给 DSH 凭据服务；读取状态时只显示是否配置、来源与能否修改，不回显密钥。清除已有凭据也需要确认。

Kimi 等账户继续使用 DSH 已有登录或模型凭据。出现缺少凭据、登录失效或接口不支持提示时，先按提示检查相应账户；不是所有服务商都提供余额或额度查询接口。未提供真实余额不会阻止本地用量继续记录。

## 从独立 Bottom Info Bar 切换

1. 如需保留原插件统计，先在独立 `dsh-bottom-info-bar` 中导出留档。
2. 在 DSH 插件管理中停用独立 `dsh-bottom-info-bar`，避免重复信息入口。
3. 启用鲸梦 0.8.7，完整退出并重新打开对应 Desktop 或 Web Host。
4. 在鲸梦的 **信息栏** 页使用自动适配，或切到自选常显后选择、排序。

鲸梦使用独立的 `$DSH_HOME/whale-dream-info/` 目录；未设置 `DSH_HOME` 时，目录为 `~/.dsh/whale-dream-info/`。**不会自动迁移或合并独立插件的旧账本。** 原插件文件继续保留，鲸梦从启用后开始累积自己的记录。升级鲸梦时保留这个目录和 `whale-dream.json`。
