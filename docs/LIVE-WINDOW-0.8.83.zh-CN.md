# 鲸梦实况窗

## 启用和操作

1. 在 Windows x64 版 DSH 的「插件」中安装 `dsh-whale-dream-0.8.83.tgz`，重启 DSH 并启用鲸梦主题。
2. 打开 **设置 → 鲸梦主题 → 实况窗**，启用「显示实况窗」。同页可更换停靠位置、调整自动收起、选择精简动效或隐藏会话详情。
3. 悬停胶囊进入「实况」，用箭头或圆点切到「会话」。在列表内滚动，点任意会话回到 DSH。
4. 关闭「显示实况窗」即可退出胶囊。重新启用会沿用上次的停靠和显示设置。

## 并行会话与用量

胶囊只显示「空闲」和「思考中」两种状态。多个会话同时处理时，实况窗汇总思考中数量，列表分别显示每条会话。单条结束后，其余会话继续计入思考中。会话行附上当前模型和 API 渠道已记录的用量。不同渠道各自显示金额或 Token 等指标。关闭「显示会话详情」后，胶囊中的标题、模型、渠道和用量会一起隐藏。

## 流畅度验收

在日常显示器上反复悬停、移出，展开途中可以反向收起。展开后快速切换两页，滚动会话列表，同时让两条会话处理请求。用标准动效和精简动效各体验一轮，再切换深浅主题、核对停靠和文字对比度。

实况窗以本地进程管道接收会话及设置变化，连续到来的快照可以合并。胶囊稳定后原生窗口按需绘制，流光跟随展开播放。用量变化不触发原岛仔的额度查询或后台功能。
