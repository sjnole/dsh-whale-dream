# 鲸梦 1.0.1 · Mac 构建与验收

适配目标为 Apple 芯片 Mac、macOS 13 或以上，以及官方 DeepSeek Harness 桌面版。Mac 与 Windows 共用插件包、设置和实况窗界面。Mac 端从包内的 `native/macos-arm64/whale-live-window` 加载原生组件。

## 构建

在 Apple 芯片 Mac 的终端，进入源码根目录。需要本机的 Xcode 命令行工具、Rust，以及 Node.js 22.13 或以上。运行以下命令。

```bash
bash scripts/build-macos-release.sh
```

脚本运行实况窗测试，构建并校验 arm64 程序，保留可执行权限，并把安装包写入 `macos-dist/dsh-whale-dream-1.0.1.tgz`。默认临时签名用于本机开发测试。具备发布证书时，可通过 `WHALE_MACOS_SIGN_IDENTITY` 指定签名身份。对外分发前，需用实际发布包验证签名、公证和从下载到启动的完整流程。

## 在 Mac 上验收

1. 在官方 DSH 的插件页添加本地 `.tgz` 并启用，按 ⌘Q 完全退出 DSH 后重新打开。
2. 在 **设置 → 鲸梦主题 → 实况窗** 启用。切换浅色和深色主题，检查折叠与展开的显示、菜单栏和摄像头刘海的避让，以及透明区域的鼠标穿透。
3. 从顶部拖动条将实况窗拖到另一台显示器。检查不同缩放的显示器、全屏空间、拔掉外接屏后的回退和重启后的位置恢复。
4. 点击会话标题回到 DSH，从实况窗用中文输入法回复。检查切换会话、按 Enter 发送，以及思考中、未读和提示音。
5. 从 Finder 拖入和复制文件，用 ⌘V 分别粘贴文件、截图和普通文字。回到主窗口检查草稿、附件删除、提交结果。用测试会话验证审批、方案确认和提问。
