## 已验证的行为

### 标题与原生输入区域

- 标题精确为「鲸梦×探索未至之境」。只在原生新会话欢迎区替换目标文字，保留图标、预览版标记、输入节点和草稿；历史消息文字不受影响。
- 信息栏使用原生 `conversation.input.right`，位于模型 / SJ 圆环之前。新会话和历史会话共用入口；原 SJ 对只读子会话的隐藏规则继续保留。
- 详情挂到 body，关闭、卸载和重新启用时不会留下重复入口或旧弹层。

### 常显、宽度与独立设置

- 13 项常显内容可勾选、取消和排序，默认余额或额度与本会话费用；全部取消时保留图标入口。
- 在明确模拟的工具栏宽度 1400 → 620 → 1400 下，六个选中字段依次全部显示、只将溢出的末尾项收进 `+N`、恢复完整显示。适配过程不改保存顺序，也不写原生父元素样式。
- 首页三个同级入口为「主题配色 / 外观与动态 / 信息栏」。信息栏偏好独立持久化，不加入主题方案，应用默认或自定义主题不会覆盖其选择。
- 「我的方案 → 创建新主题」与创建页底部「保存当前搭配」继续可用；保存失败、异步完成、离开页面和重载恢复的既有检查通过。

### 账户、费用与真实数据口径

- 并排会话的费用相互隔离；模型选择通过原 SJ 与模型目录完成，摘要和详情随当前模型切换。
- 订阅测试同时展示 5 小时剩余 72% 与每周剩余 0%，真实零额度不会被隐藏；云账单按 `currentPeriodSpend` 展示美元金额；未知模式保持中性账户状态，不误用空订阅块或旧套餐数据。
- 未提供的余额、未知价格和不同币种分别处理，不生成假余额或擅自换汇。真实余额 API、桌面账户、订阅和云账单响应使用明确的测试数据。
- 相同会话请求去重，迟到响应不串到新模型或其他会话；刷新失败保留最近有效结果；页面隐藏后停止轮询和在途请求。
- 使用实际 SQLite worker 验证四档汇总、滚动时间边界、子代理归属、流结束只记一次、CSV / JSON 导出和清空；生成期间拒绝清空。
- 清空必须取得 `cleared: true` 才报告成功。凭据修改只接受约定的引用名，不回传已保存密钥；接口继续通过宿主授权检查。

## 验证边界

测试运行于 Node.js 24.22.1。DOM 交互使用 JSDOM 和明确的模拟宿主、账户、模型目录与尺寸；账本验证使用真实 SQLite worker，但账户响应并非真实用户账户。**本轮没有启动浏览器，没有在用户 Windows DSH 或不同配置电脑上完成真机视觉 / 性能验收。** 模拟宽度检查证明测量与收纳逻辑接通，不能当作实际浏览器排版截图。
