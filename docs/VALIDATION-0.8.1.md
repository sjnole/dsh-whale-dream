官方接口基线保持 DSH `dsh-v0.2.2-rc.3`，提交 `38a6a5c965aa99ab525161efb7cc5cf1fe62fced`；Dream Skin 11.7.0、ASCII Whales 0.1.6、SJ 推理圆环 0.1.4 的来源与许可证保留。0.8.0 的完整记录保存在 `VALIDATION-0.8.0.md`。

## 最终执行结果

`npm run check` 完成：TypeScript 类型检查、生产构建、单文件 HTML 导出全部通过；统一自动回归 **370 项通过，0 失败、0 取消、0 跳过**，测试运行耗时 110611.268021 ms。

完整输出为 `test-results.txt`。本轮不只检查某几个静态帧：新增连续时间采样、连续点击、动作交接、游戏累计结果、resize、输入框异步替换和真实阅读列测量回归。实际导出 HTML 在 JSDOM 执行，生产图形由 `@napi-rs/canvas@0.1.100` 绘制；它是开发验证工具，安装插件无需此依赖。

## 确认并修复的根因

| 问题 | 原因与改动 |
| --- | --- |
| 连点让角色与光影抽动 | 最新事件的 age=0 覆盖未完成动作。星空、小伙伴与微缩世界按完整动作合并忙碌点击；点阵短反馈仍正常。机器人从挥手到疑惑使用 burstTime 平滑过渡。 |
| 翻书完成后回到旧世界 | 旧事务明确执行 return-page。现在以每个引擎的稳定 session 保存有界书页时钟偏移，60 秒事件裁剪不会撤销新世界。 |
| 点击时卡帧 | 原指针处理会同步重绘整幅场景；现在合并到已有 RAF。塔防改为 session 增量模拟，新点击只进入下一步，不再重建未来整轮。 |
| 植物细节闪烁 | 按绝对位置重新像素取整改变花瓣轮廓；现在稳定局部形状、平移旋转，并复用有界原语缓存。 |
| 动作瞬移或翻面 | 修复居民取模传送、气泡变化速度乘绝对时间、抛星交接断点、机械臂穿过肩根导致肘部翻转。 |
| 循环切换突兀 | 平滑季节、夜色、云层边缘、星云出生、星图聚散、迷宫换局、引力投星下一布局与游戏远景滚动。 |
| 矿车货物跳位 | 每颗星石保持固定货位，落入、车厢、倾倒使用同一坐标函数；车轮角度跟随实际位移。 |
| resize 换局 | 棋盘类保持当前逻辑棋盘与局内进度，等比适配；下一局再采用新视口。自由场地映射实体位置，塔防不丢身份和血量。 |
| 部分棋盘大小滑块无效 | 拓扑上限使不同大小得到相同网格。改为主体尺寸始终响应大小参数，预览、新 session 和运行中的局面都有像素差异，同时保留局内计划与时钟。 |

同一引擎的 session 在配色、尺寸、场景阶段与 runtime 设置变化后保留；更换外观或卸载才丢弃。各 session 的状态使用 WeakMap，有界缓存不会成为跨会话共享的故事进度。

## 新建会话与历史会话布局

- 非海洋外观的新会话测量同一会话的 `[data-composer-card]`，优先使用输入框上方的居中可见舞台；空间极小时使用更大的未遮挡纵向区域。主体不放进输入框后面，不更改原输入框位置、焦点、草稿或层级。
- 输入框展开后若可用舞台任一边不足 64px，暂停场景时钟并清空旧画面；空间恢复后继续原进度，避免把整幅外观挤成细条或持续重绘不可见内容。非法、零尺寸也不会进入绘制。
- 全部 30 个非海洋外观实际像素测试：输入框上方有主体，输入框矩形内没有被遮住的场景像素。
- 历史会话保留完整画布和中央主体。微缩世界、植物、小伙伴与星空在左右阅读边带补充可辨认的实物；游戏的塔、敌机航道、矿车装卸点等利用真实两侧区域。
- 官方列宽可能是 clamp/min/calc 表达式，不能 parseFloat 后回退固定 748。现在优先测量同会话 `[data-chat-flow]`，绘制布局与 Canvas 的阅读遮罩共享测量边界。
- ResizeObserver 观察 Canvas、输入框和阅读列；子节点观察只针对新出现或被替换的输入框/阅读列补充更新，不因普通流式文本逐字重建场景。
- 明确回归异步插入/替换输入框、1600px 会话的 920px 实测阅读列、正文宽度改变、输入框变高。原海洋几何与游动仍保留；从非海洋切回海洋时清理专属测量变量。
- 原生构图图套用了与生产相同的 86% 正文保护和 48% 历史透明度，并叠加说明性输入框/正文；不是只看无遮挡透明图。

## 视觉修订

- 月环行星去掉重叠半透明像素造成的网格接缝，使用阶梯轮廓、连续光影与分层纬度纹理；棱镜补充玻璃面层次。
- 微缩世界调整纸张、木铜、青绿等材质关系；树冠改为有层次的叶面，去掉载体的横向接缝。
- 小伙伴提升头身轮廓、材质、高光与表情可读性；植物减少杂乱重叠并稳定枝叶细节。
- 游戏统一主题色关系，减弱过强网格与彩虹对比；消除宝石更大、间距更清楚，砖块按行组织颜色，浅色主题增加主体对比。
- 保持透明背景、用户渐变、像素风、大小/速度/丰富程度/字体参数。没有新增设置项、外观或默认主题绑定。

## 连续性与专项验证

- 小伙伴/植物：动作任意阶段进入、连点、burst 过渡、气泡、抛星、机械臂 120 Hz 连续采样、缓存复用、左右构图。
- 微缩世界：30/60 Hz 翻页与居民采样，动作完成、60 秒历史裁剪、第二次点击、配色与尺寸变化、独立会话。
- 游戏：30/60 Hz session 连点，已发生伤害不倒退、相同 serial 不重复执行、累计结果与旧碰撞模型一致、resize 保局、矿车和挡板连续性；预览/新 session/运行中大小参数生效，900×1、900×64、64×900、1800×64、64×1800 的底层几何有限且不抛错。
- 星空：连点前后实际像素一致，星图/星云循环边界的像素差异约束，原有轨道、点击目标、参数与宽窄视口测试保留。
- 引擎：点击不重复同步绘制、相同尺寸通知不清空 Canvas、24 FPS 正确保留余数、单一 RAF、相同外观进度不重置；输入框完全遮挡时暂停及收起后的连续恢复。
- 原 38 项选择、主题与渐变、方案保存恢复、7 类分钟轮换、背景/输入框点击、隐藏/离屏/输入暂停/减少动态、卸载清理及 SJ 原交互继续进入统一 gate。

## 交付一致性与边界

`whale-dream-preview-0.8.1-r1.html` 与 `dsh-whale-dream-0.8.1.tgz` 嵌入同一生产客户端，打包脚本核对脚本与哈希。完整 ZIP 包含源码、测试、说明与本轮审查图。0.8.0 原方案清单仍在 `APPEARANCES-0.8.0.zh-CN.md`。

未在用户 Windows DSH EXE 中安装运行，未完成真实浏览器整页/GPU 合成验收，也未运行完整 Gateway 或 Lexical 编辑器。JSDOM 中的 DOMRect 使用明确模拟值，因此不能据此承诺真实设备帧率、所有第三方插件组合或未来 DSH 版本兼容。棋盘在当前局 resize 后可能暂时有留白，到下一局再按新比例排布，以保留进行中状态。
