# 鲸梦 0.8.8 · 字符鲸鱼启动首屏验证记录

## 实现范围

- 以 0.8.7 的现有主题、38 个外观、信息栏和 SJ 圆环为基线。
- 在「鲸梦主题 → 外观与动态」最上面的原说明位置置入一个 **启动首屏动画** 开关；未增加新设置菜单。该开关单独保存，不跟随主题方案切换。
- Host 使用可用的 WebServer `tapIndex` 在页面启动时注入首屏；Desktop 无 index Hook 时，由同一插件客户端自举。
- 画面由用户提供的字符鲸鱼参考提取可控制亮度网格，在 Canvas 中逐字绘制，不加载静态鲸鱼背景截图或任何音视频素材。
- 标题：鲸梦×探索未至之境；跳过与 Esc；结束淡出首页；启动首屏不出现预览版标签、百分比、状态卡或进度条。

## 已执行

1. `node --test tests/startup-integration.test.mjs`：7 项通过，0 失败。
2. `node --check`：`lib/client.js`, `lib/index.js`, `lib/startup/boot.js`, `lib/startup/host.mjs`, `build.mjs` 无语法错误。
3. 通过本地 Chromium 的 HTML DOM + Canvas 运行检查：1440×900 自动结束并清理、设置开关替换原说明行、关闭/开启写入偏好、600×600 和 1920×1080 下 Esc 清理、开启减少动态时不显示首屏、关闭开关时不创建画布，均通过。
4. 在 1440×900、1000×700、600×600 查看动态中间帧；设置页截图显示仅一个开关，没有多余顶级菜单。
5. `npm pack --ignore-scripts --offline` 可生成安装包；核对内含宿主 Hook、字符绘制、UI 开关、许可文本和原有功能代码。
6. `qa/export-preview.mjs` 导出的 HTML 内嵌与 TGZ 中同一份 `lib/client.js`。

- 字符跃水轨迹和色彩以浏览器模拟为准；不同硬件的真实 FPS 需要 DSH 客户端验收。
- 对用户关闭的偏好不会通过主题切换重新开启；独立 `dsh-startup-screen` 如同时启用可能出现双重遮罩，请停用独立插件。
