# 鲸梦 1.3.0 · 当前使用名片与用量统计

1.3.0 以 **1.2.4 的附件与气泡行为**为基准，整合最新版主题页与用量统计：

- **当前使用名片**：鲸梦主题顶部展示当前套装的横幅、头像与头像框，支持就地修改头像/昵称与「恢复默认」；38 套动态外观与左下角账户卡同步。
- **用量概览**：账户余额或额度、累计花费、今日花费、近 30 天、累计 Token、今日 Token。
- **统计范围 TAB**：读取 DSH 模型设置中的 API 与模型，默认选中最近 30 天用量最多的模型；标签为短名称，模型多时可横向滚动，新增模型自动补标签。
- **计费口径适配**：余额账户显示实时余额；订阅账户显示额度窗口、积分或余额；账单账户显示本期账单或用量。额度低于 20% 使用警示色。
- **Token 活动**：按月回看约 13 个月，展示本月 Token、本月消费、日均 Token、活跃天数与环比。
- **模型用量**：跨全部 API 汇总当月每个模型的 Token 用量、占比与请求次数，所选模型高亮。
- **附件与气泡**沿用 1.2.4：上传附件、附件编号引用、文件历史引用、发送气泡保持 1.2.4 行为；不包含 1.2.5 的独立「个人资料」设置页。
- **性能**：账户卡观察器不再扫描会话正文的流式文本；窗口隐藏时暂停外观同步；用量快照改为 60 秒、历史日桶最多 2 分钟重取一次，模型目录检测改为 5 秒。

安装 `dsh-whale-dream-1.3.0.tgz`，不要解压；升级后完全退出并重启 DSH。

## 鲸梦 1.2.4 · 实况窗

在官方 DSH 桌面版的 **设置 → 鲸梦主题 → 实况窗** 打开「显示实况窗」。悬停预览，单击固定展开，按 Esc 收起。点击收件箱查看待确认和新回复。实况窗沿屏幕顶部左右拖动，也可拖到另一台显示器。设置页可调整形状、收起信息和完成提示音，或开启演示模式暂时隐藏会话详情。[使用与验收流程](docs/LIVE-WINDOW-1.2.4.zh-CN.md)

Mac 对应 Apple 芯片，原生实况窗需要包含 macOS 组件的安装包。[Mac 构建与验收](docs/MACOS-BUILD.zh-CN.md)

主窗口的图片缩略图和文件共用一排。点附件编号可在光标处插入引用，同一附件可在一条消息中反复引用。移除附件会同步清除它的引用，保留已输入的文字。每条发送的消息从 1 编号，点发送后正文里的编号可定位本条附件。

标题栏的文件图标可打开「文件历史」，默认显示「输出内容」。「来源」按最近上传时间呈现文件。每次使用都显示对应消息的简短摘录和时间，点击可定位原消息。同一文件的多次使用可以展开查看，支持的文件可重新引用到正文，打开方式菜单可选择应用或查看本地位置。实况窗支持拖入或粘贴文件，两处按会话共用草稿文字和附件。

## 安装到官方桌面版

使用客户端内的插件管理安装本地 `.tgz` 即可，无需另装 Node、npm 或 pnpm。

1. 下载 `dsh-whale-dream-1.2.4.tgz`，**不要解压这个文件**。Mac 需要包含 macOS arm64 原生组件的包才能启用实况窗。
2. 打开 DSH 左侧 **插件 → 已安装**。如果仍启用了独立的 `dsh-dream-skin`、`dsh-ascii-whales`、`dsh-sj-reasoning-ring`、旧 `dsh-codex-effort-slider` 或 `dsh-bottom-info-bar`，先关闭其组合包开关，避免重复主题、画布、圆环和信息入口。保留原配置即可。
3. 点击 **添加插件**，输入安装包的完整路径，例如：

   ```text
   C:\Users\你的用户名\Downloads\dsh-whale-dream-1.2.4.tgz
   /Users/你的用户名/Downloads/dsh-whale-dream-1.2.4.tgz
   ```

   输入框只填实际路径；“复制文件地址”带有外围双引号时，去掉这两个引号。
4. 点击 **安装**，核对完成页上的版本为 **1.2.4**，再点击 **立即启用**。直接关闭完成页会保留“已安装但未启用”的状态。
5. 首次从独立插件切换或升级后，完成当前工作，Windows 从托盘退出 DSH，Mac 使用 ⌘Q。再重新打开 DSH。
6. 打开 **设置 → 鲸梦主题**。在「主题配色」选择默认主题，在「外观与动态」选择七类外观，在独立「信息栏」页勾选常显内容；自定义主题从「我的方案 → 创建新主题」进入。

**已有旧鲸梦时**，先在插件页卸载旧 `dsh-whale-dream`，再安装 1.2.4。保留 DSH 数据目录及 `whale-dream.json`。独立原插件只需停用。

这些入口及 tarball 支持来自 [DSH 官方插件管理说明](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.3/packages/client/ui-plugin-manager/README.zh.md)；完整退出行为来自 [官方 Desktop 说明](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.3/apps/desktop/README.zh.md#closing-the-window-and-quitting)。更多安装、升级与恢复步骤见 [docs/INSTALL.zh-CN.md](docs/INSTALL.zh-CN.md)。

### 官方 Web 版

在运行 DSH Web 的机器上，把本地安装包加入对应 Web profile：

```sh
dsh plugin --profile web add "/实际路径/dsh-whale-dream-1.2.4.tgz"
```

然后重新启动对应的 `dsh web` 进程，并刷新页面。Web 和 Desktop 的插件安装及启用状态分别管理。连接远端 Web Host 时，路径必须是 **Host 机器上的实际路径**。

**普通 npm 安装的 `dsh` 不能管理 Desktop profile。** 官方 Desktop 自带命令是另一个入口，需通过应用菜单的“管理 dsh 命令…”确认；不要把上述 Web 命令直接换成 `--profile desktop`。具体区别及可选的 Desktop 命令用法见[安装说明](docs/INSTALL.zh-CN.md#desktop-cli)。官方依据：[CLI profile 说明](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.3/apps/cli/README.zh.md)、[Desktop 内置命令运行时](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.3/apps/desktop/README.zh.md#bundled-command-runtime)。

**启动诊断（0.8.45）：** 完整退出 DSH 后重新启动；按 F12 打开开发者工具，在 Console 输入 `window.__WHALE_DREAM_STARTUP__?.getMetrics()`，可看到 `firstFrameMs`、`videoFrames`、`droppedVideoFrames`、`longTasks`、`blockedMs`、`transferBytes` 等字段。Windows 总 CPU 峰值需通过任务管理器观察，浏览器 JS API 不提供准确的宿主总 CPU 数据。启动动画可以在「鲸梦主题 → 启动首屏动画」关闭。

## 默认主题与「我的方案」

默认主题保留原来的八款：沉静蓝、极光青、星云紫、余烬橙、子夜黑、iOS 扁平、干净明亮、Material 粉。切换它们会恢复该主题的配色、原版渐变及材质，**不会更换你选中的外观，也不会重置外观动态、自动更换间隔或圆环动效**。

创建自己的完整搭配：

1. 在首页 **外观与动态** 选择外观、点击互动和更换间隔，再进入 **主题配色 → 我的方案 → 创建新主题**。
2. 创建页以当前搭配为起点，在 **配色 / 背景 / 圆环** 中调整，效果立即生效。
3. 页面底部保留 **保存当前搭配**：检查或修改方案名称，点击 **保存方案**。
4. 保存成功后回到 **我的方案**，新主题已加入列表并处于使用中。即使此前使用已有自定义方案，这一步也会新建，保留原方案。

首页不再放置「保存当前搭配」或「调整当前主题」按钮。创建页的 **返回我的方案** 回到方案列表；在当前设置窗口内切换页面会保留名称草稿。未点击保存时不会新增方案，当前效果仍按原有机制自动记住。

已有自定义方案被调整后，可在该当前方案卡片的 **管理 → 保存修改** 中更新收藏；**恢复已存版本** 可恢复收藏中的效果。想保留两个版本时，从 **创建新主题** 另存一份。管理中还可重命名或删除，删除保留当前画面。方案最多 30 套、名称 1–40 字、合计 2 MB（含内嵌图片）；这个限制与外观目录数量无关。

配色、背景和材质只在一个位置编辑；主题编辑页不重复放置外观选择。低频的图片轮播、文件夹和定时刷新在 **背景 → 图片壁纸 → 更多图片功能**。设置不再提供「扩展与维护」页面，搭配的保存与恢复统一使用「我的方案」。

完整操作说明见 [docs/THEMES.zh-CN.md](docs/THEMES.zh-CN.md)。

## 按间隔更换和动态调节

在首页 **外观与动态** 中选择 **固定使用** 或 **按间隔更换**。开启自动更换后，在 **更换间隔（分钟）** 输入 1–10080 的整数，默认 60 分钟；按 Enter 或点击其他位置后生效。例如填写 30，就会在当前外观继续显示 30 分钟后，换成同类另一种。

动物只在 8 种海洋动物中更换，游戏和植物各在自己的 5 种内更换。每次排除当前外观，连续两次不会相同；不是固定顺序轮播，也不保证一轮内每种只出现一次。启用或修改间隔会从当前时刻重新计时；设置旁显示当前类别、间隔与下一次更换时间。

关闭应用、休眠或页面暂停而错过一次或多次更换时，下次打开或恢复只补换一次，再开始新的间隔。后台没有独立服务。点击任何具体外观卡片会关闭自动更换并固定使用；分类标签只浏览，不改变当前外观或随机范围。

旧版本已开启每日随机但没有分钟字段的设置与方案，升级后按 1440 分钟保留原有的一天频率，从首次载入开始计时；之后可以自行修改，不再等待每日固定时刻。新配置默认 60 分钟，默认仍为固定使用。自动更换只改变外观，不修改主题配色、背景、动态强度和 SJ 设置。

「轻柔 / 舒适 / 灵动」提供快速动态强度；大小、速度、数量等细节默认折叠。海洋动物保留鱼群、摆尾和尾迹参数，游戏和植物使用独立的场景速度、大小和丰富程度。海洋保留字符样式、字符大小与字体；其余类别提供「像素纹理」「纹理颗粒」与纹理字体，粗细只影响次要细节。输入时暂停、离屏与隐藏暂停、减少动态效果和帧率上限对所有类别生效。

## 自动性能保护与电脑自检

自 0.8.3 起，插件会根据当前场景持续测得的同步绘制耗时，临时减少每秒绘制次数；有余量后逐步恢复，最高不超过你设定的帧率。它不改写设置，不缩小外观，也不重置游戏、点击动作或场景时间。高 DPI 下，背景内部像素总量控制在约 829 万，保持完整 CSS 场景尺寸；超过预算时背景细节会适度变柔。

自动保护不增加新的配置项。较旧电脑或同时运行多个任务时，可以先用 20 FPS；通常从 30 FPS 开始，有余量再提高。这是起始建议，不能代替目标电脑的实际测量。

完整 ZIP 中的 `whale-dream-performance-0.8.8.html` 是独立离线自检页：在要测试的电脑上用浏览器打开，点击开始，约 40 秒后下载结果。保持窗口可见、窗口大小和缩放不变；换电脑时使用相同浏览器版本、窗口与电源模式。页面使用实际背景引擎，记录绘制帧率、浏览器回调间隔、内部绘制成本和可用的长任务数据，不读取会话、不上传数据。它不包含真实 DSH 消息排版和模型输出，结果不等同于完整 DSH 性能。

0.8.3 的性能实测、修复记录和测试边界见 [历史性能报告](docs/PERFORMANCE-0.8.3.zh-CN.md)。0.8.8 继续沿用这些优化；该报告中的数据属于 0.8.3，不作为本版的新实测结果。当前检查记录见 [验证说明](docs/VALIDATION.md)。

## 点击效果在哪里看

在 **外观与动态** 打开「显示动态外观」与「点击互动」，关闭设置后点击会话的空白处，或点击可编辑的聊天输入框。点击互动默认开启；升级会保留你之前主动关闭的选择。

海洋会出现点阵水波，并保留原有的小鱼惊散；游戏与植物分别使用宝石、方块、火花、游戏像素、花瓣或叶片等反馈。反馈随外观主色变化，短暂出现后消失；它不受尾迹强度或正文背景淡化的限制。即使把海洋尾迹设为 0，点击反馈仍可显示。

输入框反馈绘制在输入卡片内部的局部装饰层，保持 `pointer-events:none`，不改变原来的点击、焦点、选区和草稿。开启「输入时暂停」后，背景动画与背景互动仍暂停；主动点击输入框仍可看到局部反馈。

消息正文、代码、链接、按钮、菜单、SJ 圆环及只读、禁用或非编辑态输入区域不触发。隐藏外观、仅新会话模式下的历史窗口、系统减少动态效果，以及离屏或页面隐藏期间不播放；外观页会提示隐藏、显示范围和系统减少动态的状态。

## SJ 圆环

内嵌的是 SJ **0.1.4 的实际生产组件**，默认收起尺寸为 34 px，展开圆盘为 160 px，环宽 15 px；小环会跟随宿主明确可识别的发送按钮尺寸。等级文字位于内圈，无额外收起按钮。

点击小环展开；选择模型后只关闭模型列表，圆环保留。模型列表打开时，首次点击圆环内其他位置只关闭列表，不会同时改变等级或团队开关。外点或 Escape 可关闭，历史会话中关闭团队协作会先显示确认。

圆环内盘、文字、轨道、焦点和菜单随主题配色；内盘和菜单保留不透明底层。单人模式为单色等级，团队模式保留原 SJ 的多彩环。设置页可调整「圆环动效」「已经过的刻度」和团队星点。发现仍在启用的独立 SJ 或旧滑杆时，鲸梦会提示处理重复入口，不会擅自停用它们。

## 信息栏：紧凑常显与统计图

入口位于输入框内 **SJ 推理圆环左侧**，利用左侧剩余宽度。常显根据内容选择「图标＋数值」或「短文字＋数值」，不再把图标和字段名称重复叠加。费用保留「会话 / 今日 / 30天 / 累计」及金额，删除费用图标；余额保留钱包及金额。额度和 token 已有窗口标记或方向箭头，不再附加相同含义的图标。悬停、键盘聚焦及详情均保留完整说明。

有字段可见时，最左侧总统计图标不再占位；没有选中内容或空间不足以容纳任何字段时，保留可点击图标入口。缓存、上下文的细比例条放在数值下方，不再横向叠加一个条形图。

默认使用 **自动适配**：DS 官方账户优先余额、当前计价时段与会话费用；其他余额 API 优先余额、参考价与用量；订阅账户突出实际额度窗口，云账单保留真实周期和单位；无余额查询的 API 显示已有参考价与用量。没有价格的自定义网关保留 token 和未计价状态，不凭模型名猜费率。你也可以在 **设置 → 鲸梦主题 → 信息栏 → 自选常显** 中从 14 项里勾选并用 ↑ / ↓ 排序。切回自动不会删除自选搭配。

升级时，旧初始默认组合转为自动适配；改过的选择、顺序、主动清空和关闭状态继续保留，不向自选列表强加新项目。

额度、上下文占用和缓存命中率用小比例图配数字；缺少数据时保留未知状态，不画假零。详情的费用趋势按币种切换，并可展开数值明细；未计价日、无记录日与真实零费用分别处理。

DeepSeek 常显只呈现**当前状态＋下一时段倒计时**，例如「高峰 · 1h20m后空闲」或「空闲 · 3h10m后高峰」，省去重复的 DS 前缀和日月图标；悬停与详情保留完整中文时长。`h` 为小时、`m` 为分钟，避免把倒计时误读成钟表时刻。完整北京时间时段条和两档价格仍在详情的「时段规则与参考价」中。日历、价格、API 适配和未知状态处理沿用 0.8.6 的已验证规则。

信息栏偏好独立保存，配色随当前主题适配。账户、额度、四档费用、CSV / JSON 导出、清空和凭据配置继续保留；统计从鲸梦启用后开始，旧独立插件账本不会自动合并。完整操作与计价来源见 [信息栏说明](docs/INFO.zh-CN.md)。

## 保存与旧配置

外观设置、海洋偏好、圆环偏好及自定义方案共同使用 Whale Dream 的宿主持久化文件 `whale-dream.json`，同时保留当前窗口可用的本地缓存。保存状态会显示“当前设置已保存”“设置保存未完成”或“方案保存未完成”，失败时补充是否暂存本机的提示；失败可重试，读取失败时不会把未知的宿主配置当成空数据覆盖。

首次读取时，如果 `whale-dream.json` 不存在，会只读继承原 `dream-skin.json`。当前地址可读取旧 ASCII Whales、SJ 或旧滑杆的 localStorage 时，会迁移相应外观偏好；旧键和旧文件都不删除、不写回。其他 origin 中不可见的旧 localStorage 无法自动读取。

0.1.0 的薄雾参数继续兼容读取，但不再产生覆盖层。已有壁纸和自定义外观不会仅因启动就被默认方案覆盖；点击默认主题只替换主题部分；点击自定义方案才恢复其中保存的整套搭配。旧 species 配置会迁移到对应海洋外观。此前已移除的飞燕、蝴蝶、小猫、赤狐和林鹿，在当前设置或已存方案中会回退为座头鲸；方案名称、配色、背景、圆环与其他参数保留。

## 本地 HTML 预览与源码

**预览使用模拟宿主。** 它不读取真实 DSH 会话或配置，不调用模型；其中选择模型、改变推理或团队状态只操作演示 store；出现的账户、额度与费用示例也不代表真实账户数据。预览中的凭据配置只读，CSV/JSON 只导出演示记录。它不等于在实际 DSH/Windows EXE 中完成的安装或视觉验收。演示数据按预览版本隔离保存，不删除旧版预览数据；本地文件夹壁纸等宿主能力需在安装后的插件中使用。

## 启动首屏动画（0.8.8）

「设置 → 鲸梦主题 → 外观与动态」顶部的「启动首屏动画」开关直接控制启动演出，默认开启。关闭后重新启动 DSH 将直接显示首页，不创建首屏画布。启动页面采用用户确认的巨型字符鲸鱼设计，沿用鲸梦主题底色/渐变及品牌图标；不包含第三方语音或影片素材。

启动期间可按 Esc 或点击空白区域跳过；当前版本不额外显示「跳过」按钮。系统开启减少动态效果时只显示静态最终标题，短暂停留后进入首页。为了避免每次新建会话重播，当前窗口会话只自动播放一次。桌面启动如未提供 WebServer 的 index 注入接口，客户端会在前端可用时自举。与独立 dsh-startup-screen 同时开启可能重复覆盖，建议停用独立启动屏。

来源研究： [@6shenhonghong9 / dsh-startup-screen](https://github.com/6shenhonghong9/dsh-startup-screen)，MIT，许可见 `licenses/dsh-startup-screen-LICENSE`。具体与 DSH 0.2.2-rc.3 的实机适配仍须在目标客户端核对。
